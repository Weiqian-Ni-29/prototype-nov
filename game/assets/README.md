# Asset sources

- `fonts/NotoSansSC.ttf`: Noto Sans SC variable font from [google/fonts](https://github.com/google/fonts/tree/main/ofl/notosanssc), distributed under the SIL Open Font License in `fonts/OFL.txt`.
- Three-dimensional character meshes, rigs and terrain geometry are original project code under `scripts/presentation/`. They are assembled at runtime and shared between exploration and battle.
- Character portraits, textures and audio are being added during MVP development. Their source and generation records will be listed here when integrated.

Do not redistribute the locally installed Godot editor in the source tree. Exported test builds use the installed standard Windows export templates.
