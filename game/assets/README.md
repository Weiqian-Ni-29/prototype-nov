# Asset sources

- `fonts/NotoSansSC.ttf`: Noto Sans SC variable font from [google/fonts](https://github.com/google/fonts/tree/main/ofl/notosanssc), distributed under the SIL Open Font License in `fonts/OFL.txt`.
- Three-dimensional character meshes, rigs and terrain geometry are original project code under `scripts/presentation/`. They are assembled at runtime and shared between exploration and battle.
- `portraits/hero.png`, `cen.png`, `lorne.png`, `eve.png`, `ember.png`, `tide.png`, `grit.png`: original illustrations generated with the built-in image_gen tool on 2026-11-04. The actual prompt set is recorded in [portrait-prompts.md](portrait-prompts.md). The game loads these workspace assets directly.
- `portraits/inn.png`, `home.png`, `exit.png`: Lu Heng, Qiao He and the return-station keeper; generated through the same tool and recorded in the same prompt set.
- Terrain surface textures are generated by original noise/brush code. Audio cues are synthesized by original PCM code in `scripts/presentation/sound.gd`, with no external samples.

Do not redistribute the locally installed Godot editor in the source tree. Exported test builds use the installed standard Windows export templates.
