# Asset sources

The game ships original story illustrations, portraits, cards, item icons, interface artwork, and synthesized audio. The illustrations were generated with the built-in image generation tool.

`portraits/mattes/` contains opacity masks derived from the original portraits for the dialogue shader.

Noto Sans SC comes from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/notosanssc), with its license in `fonts/OFL.txt`. Godot and its third-party notices are in `licenses/`.
