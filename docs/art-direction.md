# 美术方向：手绘桌游地图与二次元角色

日期：2026-11-03。状态：方向已确认，细节待讨论；尚未生成美术资产或实现界面。

## 1. 已确认方向

- 地图：手绘桌游风，六边形地块。
- 人物肖像、剧情与角色对话：日系二次元，参考《崩坏：星穹铁道》的审美方向，采用原创角色生成。
- 探索、地图移动与战斗：使用同角色的小人偶，降低复杂动作制作量。

这三类表现共享角色身份、配色与环境语义，不要求肖像、小人偶和地图使用完全相同的比例或细节密度。

## 2. 地图与界面建议

地图采用纸张、手绘线条和适度色块表现森林、山地、遗迹、平原与沙漠。六边形边界在选中、寻路和危险预览时清晰可见，平时可以弱化格线；最终是否带立体厚度待确认。

每格应分清基础地形、地点标记、角色和临时环境状态。燃烧有火焰与状态标记，潮湿有纹理或图标，焦土有地表变化，不能只靠颜色区分。迷雾下显示最后观察信息，不能用火焰动画泄露异地未观察变化。

UI 可以采用卡牌肖像、纸质面板与棋子底座，但正文和资源数字优先保证可读。多名角色分散时支持选中高亮、角色列表定位和重叠角色展开；具体布局尚未设计。

已确认地图外轮廓为六边形，中心向外 8 圈、共 217 格；基础视野为角色所在格及相邻一圈六格，其余未探索区域用迷雾遮蔽，已探索但不可见区域暗化并保留最后观察信息。六边形朝向、视角、画面冷暖和笔触细度仍待确认。

## 3. 肖像与剧情立绘建议

人物采用清晰五官、精致发型、分层服装与适度装饰，表现日系二次元角色魅力。角色的身份、装备倾向和元素通过服装轮廓与少量关键配件体现，不依赖把复杂纹样堆满全身。

每名角色先确定一张标准设定：脸型、发色、瞳色、服装主辅色、标志配件、武器与基本性格。后续肖像、剧情表情和小人偶都以它为依据，避免每次生成像不同人物。

首轮资产建议为一张标准半身肖像和少量对话表情；是否需要全身立绘、剧情插画、更多表情和口型动画，按实际剧情需要决定。当前只写方向，不批量生成素材。

## 4. 地图与战斗小人偶建议

建议小人偶采用较大的头部、清楚的外轮廓和简化服装细节，保留肖像中的发型、配色、武器和标志配件；具体头身比例待确认。

地图角色以短距离平移、轻微起伏和选中底座表现移动；同格多人可以折叠为人数标记并展开查看。战斗沿用同一角色外观，使用站位、短促位移、受击闪光、简单施法和技能特效反馈，减少复杂骨骼动作与镜头演出。

建议优先讨论的动作是待机、移动、攻击、施法、受击和重伤；数量、方向数及是否采用少量关键帧尚未确定。2D 贴片、分层纸偶或简易 3D 人偶均能服务这个方向，技术形式未锁定。

技能需要看清目标与环境后果，自动战斗也应能读懂谁行动、谁受伤、地块如何改变。华丽效果不应遮住阵容、血条和危险预览。

## 5. 统一要求与后续讨论

- 肖像、立绘、小人偶使用同一份角色外观设定；属性图标、元素颜色和伤害提示在地图与战斗一致。
- 二次元人物与纸质地图通过共同的配色、线条与 UI 框架衔接，不强行把写实角色直接贴到地图上。
- 已采用 [《归灯之野》世界观与剧情](worldbuilding.md)：旧道路文明衰落后的奇幻边境，旅途温暖与历史隐情并存；视觉细节配合该方向继续设计。
- 尚待确认：小人偶比例与技术形式、具体笔触和配色、是否需要装备外观变化。
- 当前不开始工程、美术生成或动画制作；下一步继续讨论角色、补给、战斗与视觉细节。
