# 美术方向：手绘桌游地图与二次元角色

更新日期：2026-11-05。状态：2.5D 探索/战斗、共用完整骨骼人偶、角色肖像与 MVP 地景已实现。具体资产版本、许可和实机证据见 [升级记录](animation-upgrade-progress.md)。下文保留视觉方向及后续建议。

## 1. 已确认方向

- 地图：2.5D 手绘桌游沙盘，六边形地块，有实际空间纵深，不能只做平面棋盘。
- 人物肖像、剧情与角色对话：日系二次元，参考《崩坏：星穹铁道》的审美方向，采用原创角色生成。
- 探索与战斗：复用同一套立体 3D 小人偶及骨骼，以固定斜视镜头呈现 2.5D；需要简单动画，不采用纸偶贴片替代已确定角色形式。
- 战斗背景：匹配实际交战地块的地貌、当前环境状态和天气；进入战斗不能换成无关的通用舞台。

这些表现共享角色身份、配色与环境语义，不要求肖像、小人偶和地图使用完全相同的比例或细节密度。

## 2. 地图与界面建议

地图以有纵深的六边形沙盘和手绘纹理表现平原、森林、山地、遗迹、沙漠、沼泽；纸张、线条、色块与棋子底座共同保持桌游感。具体厚度、高差与装饰密度可调整，但探索也采用 2.5D。选格、寻路与风险预览时格界清晰，平时可弱化格线。

每格分清地形、地点、角色和环境状态，以图标/纹理配合颜色区分火焰、潮湿、焦土。已探索格永久点亮并显示当前状态，只有未探索格遮雾，不用火焰动画泄露未知区域。

UI 可以采用卡牌肖像、纸质面板与棋子底座，但正文和资源数字优先保证可读。多名角色分散时支持选中高亮、角色列表定位和重叠角色展开；具体布局尚未设计。

地图为半径 8 圈、217 格六边形，角色用所在格及一圈六格揭雾，全队共享，已探索永久点亮但不透视隐藏敌人。相机采用斜视构图，具体角度、缩放、格子朝向、冷暖与笔触细度待打样。

## 3. 肖像与剧情立绘建议

人物采用清晰五官、精致发型、分层服装与适度装饰，表现日系二次元角色魅力。角色的身份、装备倾向和元素通过服装轮廓与少量关键配件体现，不依赖把复杂纹样堆满全身。

每名角色先确定一张标准设定：脸型、发色、瞳色、服装主辅色、标志配件、武器与基本性格。后续肖像、剧情表情和小人偶都以它为依据，避免每次生成像不同人物。

首轮资产建议为一张标准半身肖像和少量对话表情；是否需要全身立绘、剧情插画、更多表情和口型动画，按实际剧情需要决定。当前只写方向，不批量生成素材。

## 4. 共用的 3D 小人偶与简单动画

建议小人偶采用较大的头部、清楚的外轮廓和简化服装细节，保留肖像中的发型、配色、武器和标志配件；具体头身比例待确认。

地图移动和战斗复用同一角色模型、材质、骨架与动作，按各自场景调整构图；地图使用行走/轻跑与待机，不能仅平移无动作。战斗用简短攻击、施法、受击与倒下表达状态，固定镜头保留空间感。同格多人展示可用选中底座、展开与人数提示，具体布局待验证。

简单动画是首版要求。首轮动作清单建议为待机、行走、普通攻击、施法/释放终结技、受击、倒下；救援或胜后恢复时可用短起身或状态过渡，不因动画播放完毕就自动回血。同类型人形可复用基础骨骼动作；砾牙等四足角色用适配骨架，不强套人形动作。具体动作时长与模型规格待制作验证，不要求复杂连招或长镜头演出。

终结技可伤害、恢复或辅助，动作与特效对应真实效果，不把所有大招都表现为冲向敌人攻击。模型生成、绑定、权重与导入需要单独验证，已有肖像不等于已有可用 3D 模型。

技能需要看清目标与环境后果，自动战斗也应能读懂谁行动、谁受伤、地块如何改变。华丽效果不应遮住阵容、血条和危险预览。

## 5. 战斗背景与地块对应

背景以实际发生战斗的地图格为来源；NPC 事件交战没有前置移动时仍取当前事件格，不能随意切换地貌。以下是表现建议，具体场景资产待制作：

| 地貌/状态 | 战斗场景表现 |
| --- | --- |
| 平原 | 草坡、土路与开阔远景，保留当地的道路/营地线索 |
| 森林 | 林地、树木、灌木和树影，遮挡不掩盖必要的战斗 UI |
| 山地 | 岩坡、碎石与山体远景，不凭画面新增不可通行规则 |
| 遗迹 | 旧墙、石砖、灯路或水文设施，按实际地点身份变化 |
| 沙漠 | 沙地、风蚀岩与稀疏植被，元素修正和背景一致 |
| 沼泽 | 泥面、浅水与湿地植物；视觉浅水不擅自决定移动费或永久潮湿规则 |
| 焦土 | 烧黑地面、残木与灰烬，是地块转化结果，不是第七类基础地形 |
| 燃烧/潮湿 | 火焰、烟、湿润表面等覆盖效果，反映实际状态，不只播放一次装饰动画 |
| 晴/雨 | 同一套当前天气驱动光照与降雨；战斗本身不推进日期或改变全局预报 |

入场读取当前地形与状态，战斗点燃、灭火、浸湿即时更新同一场景对应表现，结束后回写并反映到地图。森林燃料按天消耗，不能为了动画在一场战斗里提前烧成焦土。战斗背景也不得显露未知邻格、隐藏敌人或未发现的任务信息。

建议六种地貌共享场景构件、材质和天气/状态层，探索沙盘与战斗舞台共用视觉资产库，按镜头需要组织不同细节，而不是每个地块另做完全独立背景。

## 6. 统一要求与后续讨论

- 肖像、立绘、小人偶使用同一份角色外观设定；属性图标、元素颜色和伤害提示在地图与战斗一致。
- 二次元人物与纸质地图通过共同的配色、线条与 UI 框架衔接，不强行把写实角色直接贴到地图上。
- 已采用 [《归灯之野》世界观与剧情](worldbuilding.md)：旧道路文明衰落后的奇幻边境，旅途温暖与历史隐情并存；视觉细节配合该方向继续设计。
- 尚待细化：小人偶头身比/模型规格、骨骼与动作清单细节、具体笔触配色、相机角度与装备外观变化；2.5D、3D 小人偶复用及简单动画不再作为候选。
- 已按后续开发授权完成工程和首轮资产；下一步根据试玩反馈继续打磨。

## 7. MVP 0.2.0 地景实现

陆地采用倒角六边形、土层侧面和纸纹式表面着色；森林使用纹理树冠/灌木，山地使用不规则岩块，遗迹有完整或残破柱与石板，沙漠有沙纹，沼泽有池水、芦苇和浮叶。装饰均为表现，不新增通行规则。岛外铺设五圈不可通行的蓝色六边形海格，浅海/深海过渡、岸边碎浪与延伸海面取代黑色虚空；未探索陆地继续遮雾。战场只读取当前格，不展示邻格内容。
