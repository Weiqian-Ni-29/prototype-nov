# 维洛丹故事大纲

以下内容包含最终战剧透。本文件与实际剧情共同定义现行世界观，早期《归灯之野》文档仅作开发记录。

| 战神 | 卡德兰 Kadran |

## 世界与死亡权能

龙、恶魔、神、人类、矮人和精灵生活在同一个世界。龙和恶魔可以化为人形。龙数量稀少，力量仅次于神；人形下的克制与游戏中的战斗数值不代表神职、原形力量完全相等。精灵长寿，矮人擅长锻造。恶魔来自冥界，召唤与契约有明确的代价；履约结束后可以自愿选择同行，不必把每一次善意都解释成新契约。

凡人通常只从梦、祷告的回应、神迹和灾难得知诸神的意志，极少见到真容。诸神高高在上，出手稀少，许多又喜怒无常。同一位神可以恩赐一座城邦，也可以惩罚它或收回此前的恩惠。梅文娜、多兰克和莱文索以人形化身与旅人同行。化身能出战和受伤，能施展的力量有限。

伊文洛既负责引渡灵魂，也掌握死亡本身。肉身死亡与灵魂得到归处不是同一件事。重力属于死亡之神的权能：他能借此引导亡魂进入冥界、赐予安息。旅人的重压、浮石与减缓坠落，是同一权能尚未完整恢复时的表现，并非额外获得的元素能力。

冥河是冥界的一部分，可以洗刷、剥夺、吞噬一切；它不是普通水系魔法，也不天然识别友军。决战中伊文洛约束河界、保留现世岸地，把危险控制在战神所在的范围，不能以“盟友不受冥河影响”替代这种控制。

## 战争的因果

卡德兰掌管疯狂与纷争，冲突越多便越强。他以停战会谈为诱饵，彻底摧毁伊文洛的肉体，并观察到亡灵引渡停止，因此确信对方已被彻底消灭。

卡德兰平时通过战鼓、祈祷的回应和将领的征调令影响战局。围城者和守军都能向他求胜。他能让负伤的士兵短暂忘掉疼痛，也能让他们在疯狂中继续追杀已经退走的人。凡人少见他亲临战场。故事把亲自现身的时刻留给停战会的袭击和最后的决战。

死神被杀后，亡者滞留现世，形成困路、失踪、断水等灾厄；死亡之神及其势力的制衡也随之消失。诸神更加任意地争夺与保护领地，凡人因资源短缺、恐惧、旧仇和报复发生更激烈的冲突，卡德兰由此获益。战神不能使用、控制或复活亡兵来延续战争；亡魂引发的灾害与活人的战争必须区分。

其他神知道伊文洛曾存在，却各有退缩、误判和未承担的责任。凡人的公共记忆逐渐残缺，不代表所有神与长寿种族同时失忆。残碑、旧约、神明的迟疑和恶魔的熟悉感都保留不同程度的痕迹。

## 主角归来

死之神能够重生，是其独有的特殊性，并非诸神通用规则，也不是预设的复活计划。卡德兰不知道这一点，连被杀前的伊文洛自己也不知道。

神躯在冥界经过漫长岁月重新形成，意识未恢复。一次为逃难者求援的恶魔召唤意外打开通道，把昏迷的伊文洛带到现世。村民发现并照顾了他。他在村屋醒来，失去记忆，却愿意从照顾眼前的人开始，寻找停止战争的办法。

三神面对尚未恢复权能、重生形貌有所变化的旅人，只能怀疑、求证或回避，不能无故提前确定身份。恶魔对冥界气息的熟悉只发生在面对旅人时，不能套用给单独前来交谈的普通队员。

## 四段主线

探索度达到 20%、40%、60%、80% 后，旅人下一次可以阅读主线时依次触发。探索比例负责安排节奏，不替代证据；每段提供现场目击、证言或实物记录，读过的内容可在手记中回看。

1. **留下的人**。家属向四座神殿祈求，已经下葬的亲人依然滞留。旅人察觉碎石随手势浮起，记起让亡者有归处的承诺。
2. **失去的制衡**。两名逃难者争抢水源，讲出亡魂困井、神战毁路和战神赐勇后失控的遭遇。旧约抄本证明曾有另一股神明势力约束诸方。
3. **未完成的停战会**。行者展示赴会记载、会场被毁的痕迹和引渡中断的祭祀记录。旅人记起自己曾赴会追问恩罚的代价，遇袭经过留到决战揭晓。
4. **找到战神**。信使亲自走过驻地附近的山口和河岸，带来了可以和地貌核对的路线。征调书要求两边争夺粮道，还教他们用同一段祷词求胜。

随机支线不是这四段必经证据的唯一投放点。未完成随机事件时，主线不得声称玩家已经送过某封信或拯救某位亡者。

## 决战与结尾

卡德兰再次使出当年杀死伊文洛的招式，触发身份回忆。伊文洛恢复权能后，感知冥界中重生与召唤留下的痕迹；这不是回忆自己昏迷期间亲眼看见的事情。卡德兰承认肉体尽毁、引渡停止曾让他误判。

伊文洛记起了自己原来的面貌。活人很少见他，亡者却曾在最后一段路上见过他。无论是平民、交战双方的士兵，还是生前向别的神祈祷过的人，他都愿意引渡。

伊文洛以重力为滞留的灵魂打开归途，再将冥河短暂引到现世、控制河界，剥夺卡德兰的力量。先前平息的纷争仍会降低战神开场时的力量。觉醒后的压倒性优势保留为最终收束，不改变既有战斗数值与规则。

击败战神、恢复引渡和神明间的制衡，使诸神能够停战，但不会自动修好桥梁、填满粮仓或抹掉活人的仇恨。伙伴按各自的同行抉择继续承担责任。旅人记得村民送出的第一包药，也终于履行让亡者有归处的承诺；停止战争之后，修复生活仍是众人的工作。
