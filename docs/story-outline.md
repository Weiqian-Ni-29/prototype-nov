# 维洛丹故事大纲

以下内容包含最终战剧透。

| 身份 | 名字 |
| --- | --- |
| 世界 | 维洛丹 Veylodan |
| 战神 | 卡德兰 Kadran |
| 四季之神 | 梅文娜 Mevenna |
| 大地之神 | 多兰克 Dorank |
| 天空神 | 莱文索 Levensor |
| 死亡之神 | 伊文洛 Ivenlo |

龙、恶魔、神、人类、矮人和精灵生活在同一个世界。龙和恶魔可以化为人形。龙数量稀少，力量仅次于神。精灵长寿、擅长弓术，多住在森林。矮人擅锻造，在山里建有城邦。恶魔来自冥界，经召唤来到现世，按契约履约。越高阶的恶魔要求的代价越大。各族的人有自己的经历和立场。

卡德兰掌管疯狂与纷争，世间的冲突越多，他就越强。他亲眼见过伊文洛接走阵亡士兵，知道死者归去以后战争会失去继续的机会，于是以停战会谈为诱饵杀死伊文洛。卡德兰以为自己彻底除掉了他。其他神知道伊文洛曾经存在，有的只顾自己的领地，有的畏惧卡德兰。久而久之，世人忘了死亡之神，死者滞留现世，卡德兰把一部分阵亡士兵带回战场。

伊文洛的肉身在冥界经过漫长岁月重新形成，意识一直没有恢复。一次偶然的恶魔召唤打开了两界之间的通道，把他带到现世。村民在村外发现昏迷的他，把他接回照顾。他直到在村屋里睁眼，才恢复意识。此时他失去记忆，只想结束战争。

开场介绍世间知道的四位神和战乱。随后玩家在本局地貌所对应的村庄醒来，听村民讲外面发生的事，收下补给再出发。探索度的四个门槛决定主线推进时机。旅人偶尔找回一段记忆，重新掌握与它对应的本领。重力魔法独立于火、水、冰、雷、风、土。

支线以随机地块节点呈现。解决亡灵造成的灾祸之后，旅人会凭残余权能无意识地引渡眼前的亡者。恶魔对他有难以解释的归属感，仍按自己的立场与契约行动。平息的纷争越多，卡德兰开场时越弱。

最终战里，卡德兰使出当年偷袭用过的招式。旅人记起自己就是伊文洛，然后取回完整的力量。他一次性送走滞留的亡灵，将冥河短暂召到现世。河水逐步剥离卡德兰的力量，伊文洛亲手击败他，诸神停战。
