# 维洛丹的节点和角色

种子固定地图、村庄、25 名可相遇角色的位置、节点事件和商店货物。地貌限定事件候选和背景配图。村庄、普通战斗、精英战斗、交易、补给、歇脚、寻宝、委托、线索和亡灵事件构成每局旅程。

人物随节点出现，可以先观察发生的事，再谈对方的经历和当下的打算。每名角色有单独编写的背景、性格、相遇对白、接受同行时的动作和回应，以及同行后的台词。部分人物可以交手，交手前会确认。受伤的人需要同地救助。对话的选项在相关情节之后出现。

角色的常规立绘和情绪、动作立绘使用相同的人物造型。角色的行为由自己的性格决定，例如伊芙答应同行前会先收好绷带，砾牙只是抱着手点头，铎火会扛起锤子。25 名伙伴、旅人和卡德兰各有七套立绘，分别覆盖常规、担忧、同行或对话反应、悲伤、愤怒、惊讶和战斗。三种村民各有六套。
