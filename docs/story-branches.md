# 首章分支、结局与覆盖矩阵

日期：2026-11-04。版本：分支审阅稿 0.3。状态：与 [故事细化稿](story-outline.md) 配套，已完成主 agent 审阅修订与统一检查，见 [审阅记录](design-review.md)。本文件覆盖本稿明确定义的入口、转移和终点，不声称涵盖未来所有故事或自由操作排列；只写规格，不开发。

## 1. 规则边界与状态含义

- 六名伙伴每局都在合适地点存在，但可以未被发现、未被邀请或被拒绝；这些状态不等于“已加入但没带回来”。
- 对话、剧情态度选项、邀请与交付任务不消耗 AP。真实移动、战斗、采集、环境技能、恢复物品与救援依正式规则执行，不通过对白免除费用或物品条件。
- 所有己方共享探索记录，探索地块永久点亮、地形可实时观测，不自动暴露森林等遮挡地形中的隐藏敌人。敌人固定驻守、不主动跨格追击；敌人信息必须来自真实发现或有来源的线索。地图可观测不能代替同地交谈、交物、治疗和实际交付。
- 已确认六类基础地形，包括沼泽；沼泽通行数值待定，本故事不要求独占某类地形的技能才能完成主线。敌伏击首次行动提前后恢复正常连续速度条；预算不足的伏击首次参战费可扣当前AP至0、不形成欠费，不据此免除普通主动交战费用。
- 恢复物资和任务物品由角色个人持有，容量无限，只能同格免费交接；主角打开面板不获得异地原件。
- 全队共用日期，不设每日强制口粮。剧情没有强制日数截止、自动死亡或必然错过的末班船。
- 主角到站只解锁主动结束入口，可等待、返回或继续操作其他成员。所有终点取最后确认时的真实状态。
- 终结技充能只在战斗中产生，攻击给使用者充能，治疗/保护等辅助战斗技能也少量充能，未用充能战后保留；证据、采药、拾取、对话和故事完成不提供充能。终结技可伤害、恢复或辅助，普通主动技能不统一设冷却，按正式规则耗MP并占正常行动。
- 燃烧和潮湿只影响本场战斗。弥烬支线可核对三年前的旧清障事故记录。

### 角色的三条独立轴

| 轴 | 状态 | 用途 |
| --- | --- | --- |
| 人物关系 J | 未发现、已接触、待答复、暂缓、明确不同行、已加入 | 决定人物是否属于远征队，不由任务完成自动改成加入 |
| 个人故事 R | E0 未结、已得到 E1/E2/E3 中某一具体结果 | 任务客观完成但结果未当面告知角色，仍为 E0；“得到结果”不一定是圆满解决 |
| 结束处境 X | 已到站撤离、异地可行动、异地重伤 | 仅 J=已加入时进入队员撤离统计；任务和关系结果不能替代实际位置与健康 |

终结局面可组合表达为“主线终点 + 每人的个人故事 + 入队/撤离处境 + 真实环境/证物附记”。不为每种排列机械写一份互相冲突的全世界结局。

物件的原件、授权副本、当事人口述、玩家记忆分别记录。副本只有存在实际制作/交付来源才算副本，不能因某个角色曾经看过原件就自动在其包里生成认证件。任务证明不变成可重复出售或领取奖励的资源。

Q-W是水文材料组的统称，不是让三件证物共用一个跨地图背包；Q-WA/B/C分别记录实际持有人。缺少Q-WC时，仍可选择保留差异、有限结论或不造假，不能把“人工分流已证明”写入结果。Q-T交站后由站方保管，Q-TR由实际交件者持有，二者不可同时假设仍在该角色包里。Q-T/Q-TR普通登记不计入CH主线历史材料或路况提交；只交Q-T、拿到Q-TR后离开仍可为CH-00。

已经交到归航站的材料由站方保管，不再要求原携带者也必须撤离，因而可能出现“材料到了，送材料的人没到”的结局。未交的原件仍在异地成员包里时，只能提交实际掌握的口述或已有副本。

### 3.2 主线终点选择与覆盖

“材料齐备”指 Q-A、相互对应的 Q-B、获准使用的 Q-C 已由真实原件或合法有来源副本交到站内，并核对批次；这是足以受理的材料，不是最高法院已判案。Q-D可补充，但不强制要求责任人配合才能核查。

CH-03的公开授权在M-03B有明确、无隐藏好感门槛的可达选项：实际解释用途并接受只代表乔禾本户、不代搬迁、不公开私人家信的限制后，请她按该范围署名。若选择或遇到拒绝公开，仍有密封、口述和本户条款路线；不将拒绝公开设成无法完成远征的失败。乔禾签名只能代表本户，其他16户没有在本章自动给出同意。

公开与密封是互斥的披露处理。材料一旦公开，不可下一次交谈撤回成“从未公开”；可以补充更正，但保留公开历史。先交路况或初步线索可后来补齐，且不重复发资源奖励。

| 顺序 | 终点 ID | 完整选择条件 | 必须显示的具体结果 |
| --- | --- | --- | --- |
| 1 | CH-03 | 核验材料已公开递交且相应披露有授权 | 临时路况图记入已确认住处、受理旧档核查；不宣称全大陆档案已改好 |
| 2 | CH-04 | 核验材料齐备、按证词许可密封递交，未曾公开同一私人内容 | 私人信息封存、必要接应地点有限登记；不会与 CH-03 同时当作两个独立公开结局 |
| 3 | CH-05 | 真实路线与居民授权条款已交，且未进入 CH-03/04 的核验提交路线 | 站方接收居民仍留原地的意愿与协商请求；没有自动搬迁。历史是否查明作为附记 |
| 4 | CH-06 | 玩家明确选择保留关键材料，关键材料实际随到站撤离者离开，且未将该批材料交给站方 | 文书确实带走而未交；站方只知道此前实际收到的路况或口述 |
| 5 | CH-01 | 玩家明确只提交路况，无已成立的上述终点 | 新路线已登记，历史与人口空白未因此自动解决；知道而不提交与从未知晓可有不同附句 |
| 6 | CH-02 | 已展开调查、获得线索或提交部分历史材料，但不满足上述终点 | 分为“已提交，待核查”和“尚未送达，调查停在途中”两种附句；后一种不得说站方已经收件 |
| 7 | CH-00 | 没有展开相关调查、未提交任何相关记录，主动撤离 | 过境归航，驿站故事尚未知晓，不按恶结局处罚 |

CH-02 对应细化稿中的“一条待查的线索”，现明确包含未送达情况，避免调查过却未交物的路径没有终点。若存在 CH-03/04，又递交居民条款，保持 CH-03/04 为主终点并附加“居民意愿已记录”，不抹掉真实提交历史。

机械失败时不播放“成功带回”。已实际送达的文件仍可记为“送入站内”，其余保留中断位置；是否承接到以后战役不在本稿自动实现。

## 4. 六条个人线的事件、互斥与终点

下表 E0 不是缺少文案的占位，而是本局未完成回访或未作出结论时的明确收口；具体未撤离时再进入第 7 节四类人物尾声。
