# 维洛丹的节点和角色

种子固定地图、村庄、25 名角色的位置、节点与货物。现行事件库有 108 条：交易、补给、歇脚、委托、线索、寻宝、遭遇、险地、亡灵各 12 条，六种地貌各 18 条。这不等于 108 条长篇支线。

## 亡灵事件：先查证，再告别

12 条亡灵故事分别有现场调查、证据、两种告别方式与不同收束。任何健康的同行角色可在当地调查；只有旅人健康且同地时，才能用尚未完全理解的权能引渡亡魂。调查只记见闻，不提前计为解决；选择告别方式后才平息此处灾厄，同一地点不能换选或重复计分。

- 父亲与船工所等的平安消息必须有见证或记录，不能凭空断言亲人已获救。
- 遗物必须说明现场来历，不假定背包中有未取得的任务物品。
- 矿井事件先查清人员生死与敲击缘由，再处理遗骸、纪念或封闭危险区域，不能把封井等同于安息。
- 告别在眼前场景内完成，不以一次点击假装角色已经往返远处村庄或隔空送信。
- 各种告别均尊重核实后的事实，但在私下纪念、公开传述、归还身份与留下提醒等方面有所取舍。

新生成的同一局地图中，具体亡灵故事不重复。某地貌的亡灵故事已用完时，后续候选地块改为线索节点；普通民生、交易等节点仍可复用。

## 委托与其他节点

12 条委托各有两种在场可完成的做法。两者都消耗 1 精力、获得该地点事先确定的酬劳，但处理顺序、保留的东西或需要后续承担的工作不同。同一地点只付一次，不隐含消耗背包中并不存在的工具、粮食或钱。

线索会保存具体证据，不再只在手记留下标题。手记也显示已经阅读的四段主线现场记录，以及已处理节点选择对应的后果。玩家可以回看调查依据，而不必记住一闪而过的对白。

补给与寻宝说明取得许可或物件的弃置状态，不能把为其他逃难者留下的药全部拿走后当作善举。歇脚的恢复生命、恢复魔力、带走物品保持互斥；每种选择有自己的结语，不把仅拿药写成已经睡过一晚。

## 25 名伙伴的个人抉择

人物保留各自的背景、性格、相遇对白、入队动作和同行台词。邀请入队之前，必要的责任交接必须明确：家人由谁照看、儿童的供粮谁接手、受困工友由谁救援；结伴不代表那些事情已经神奇地解决。

加入后，可以在同地、双方健康且没有当前危险的情况下谈个人心事。每名伙伴有一段独立的现场交流、两条可选路线、对应回应和个人尾声。它们是短篇个人抉择，而不是自动完成一整串跨地图任务：当场能够做到的事写为已做，战后计划明确仍待实施。

| 人物 | 个人故事重点 |
| --- | --- |
| 岑枝、霜弦、沐叶、暮柳 | 护送与留守的分寸、家人的安排、照顾队尾、向外人开放猎径的责任。 |
| 洛恩、岚翎、长路 | 守信、消息的可靠性、速度与安全、结伴送信而非凭空完成投递。 |
| 伊芙、苏茅、澄汐 | 药物分配、救治立场、证据与尚不能下结论的水源调查。 |
| 石垣、岩钉、泽栅、砧雪 | 救援交接、保护同行者、危险通道与给难民留下退路。 |
| 铎火 | 锻造者如何面对自己制造的兵器造成的伤害，保护人的手段与边界。 |
| 弥烬、闻霆、灰角、契岑 | 契约完成后的自由、承诺的分量、自愿帮助与各自留下的理由。 |
| 砾牙、铅翼、霁鳞 | 强大者的克制、误伤后的责任，以及愿意保护的普通生活。 |
| 梅文娜、多兰克、莱文索 | 保护一地却伤害另一地的错误、面对旧识的不同态度与战后的承担。 |

个人抉择保存在存档，不能反复改选刷取结果，不发额外物资，也不改变 AP、MP 或战斗数值。再次交谈可回顾已经作出的决定。结局区分未遇见、未加入、尚未选择、不同选择与受伤状态，不把一句愿望写成已经完成的善后。

恶魔对冥界气息的熟悉、神明对旅人的疑虑，只在实际面对主角时出现。普通伙伴前去交谈时，人物仍有正常的合作动机，不能把所有来访者都当成失忆的死亡之神。
