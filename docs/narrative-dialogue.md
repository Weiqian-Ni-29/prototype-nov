# 剧情与 NPC 对话设计

更新日期：2026-11-04。版本：对话草案 0.3。状态：未实现。采用 [《归灯之野》](worldbuilding.md)，已确认多支线、多选择与多结局，专职剧情稿正在细化与审阅。

## 1. NPC 对话应该承担什么

一次初遇优先完成三件事：让玩家知道对方眼下在做什么、感受到这个人的性格、决定是否参与。历史设定只在与当前选择有关时出现，不用每名 NPC 都从八十年前讲起。

建议采用预设分支对白，与地点、人物状态、已知信息和玩家选择关联；当前不引入运行时大模型对话、任意自由输入或不可检查的自动剧情。

交谈、剧情对话选项、邀请或拒绝同行、交付任务及同步领奖不耗 AP，不另设收费招募动作。采集、移动、战斗或环境技能按实际行为费用处理，不因由对白触发就免费或重复收费；剧情物品代价须明示。

## 2. 对话结构建议

每次事件记录：说话者、当前地点、参与角色、触发条件、展示文本、可询问信息、执行选项、成本预览、状态变化、奖励、重复访问版本与未满足条件的反馈。

- 可反复询问的背景问题不重复扣费或发奖励。
- 玩家拒绝帮忙可以获得正常的结束回应，不默认触发敌对。
- 真正不可逆的选择先说明可观察的代价；未知剧情可以保密，但不以模糊文案偷偷扣资源或永久移除角色。
- 同一事件由不同角色访问时共享完成状态，不能换人重新领一次奖励。
- 角色离场、重伤、未加入、物品不足和地点烧毁都有替代文本，不只写理想流程。
- 同地同行角色可以插话，异地伙伴不隔空发言。精确远程通信与日志共享规则仍待讨论。

以下示例中的括号说明用于设计，不直接作为游戏人物台词；数值费用以最终规则为准。

## 3. 示例一：猎人的初遇

场景：森林边缘。岑枝半跪在倒木旁，一根绳索绷进草丛，箭头却朝着地面。

**岑枝**：“先别往前。你再踩一步，今晚我们就只能分一锅绳子汤。”

玩家可以免费询问：

- **“你在抓什么？”**
  - 岑枝：“本来是兔子。现在网住了一只送信鸟。兔子没吃到，信也快耽误了。”
- **“归航站往哪边走？”**
  - 岑枝：“沿山脊找旧路牌。上面的箭头可能歪了，下面新刻的那个没有。”
  - （只给大致方向，不揭开未观察区域或暴露精确撤离坐标。）
- **“你为什么还守着这里？”**
  - 岑枝：“这里有家。地图上没画，不等于没有。”

执行选项：

| 选择 | 回应与结果 |
| --- | --- |
| “我按住树枝，你把它放出来。” | 帮助后岑枝提出同行意愿，玩家可选择同行、拒绝或暂缓，不另扣招募 AP；实际物理操作若有费用须单独明示，不藏在对话选择里。 |
| “告诉我安全的路，我们各走各的。” | 岑枝：“避开新烧过的坡。灰下面有时还有火。”保留后续交谈机会，不强制招募或惩罚。 |
| “我现在帮不上，之后再来。” | 岑枝：“那就看着脚下。别给我多一件事。”事件未完成，回访使用对应文本。 |

若玩家选择招募：

**玩家**：“一起去归航站？路上也许能找到更好的补给。”

**岑枝**：“我走到下一个林口。再远，看你怎么走。”

（这是角色态度，不新增未确认的强制离队倒计时；真有离队条件时必须在规则中明确。）

## 4. 示例二：火术师与仍有人使用的森林

场景：一处被野兽占据的废弃清障营地。弥烬想取回遗失的工具；若岑枝也在当前格，她会注意到营地边缘的新鲜采集痕迹。

**弥烬**：“干枝都堆到门口了。点一圈火，它们自己会退。”

**岑枝（仅同地时）**：“火会退，还是树林会退？”

**弥烬**：“……你觉得这片林子还在用？”

**岑枝**：“那根绳上晾着药草。昨天挂的。”

若岑枝不在场，改为主角从地块详情看到“近期采集痕迹”，弥烬补一句：“有人昨天来过。那就不能只算眼前这一仗。”不让缺少某位伙伴导致玩家看不到关键风险。

玩家可选择：

- **“先看清楚附近有什么，再决定怎么打。”** 提供战前环境预览，不免费执行一次侦察技能。
- **“用火，但先确认后果。”** 预览燃烧可能伤害双方、影响林地资源；点燃必须由有相应技能的实际行动者执行并支付费用，不靠选对白白送一次法术。
- **“先绕开这里。”** 不触发战斗，保留遭遇。

这里的对白提供战术背景，是否点火仍由正式战斗或探索指令决定；不将对话选项当成绕过 AP、MP 或四人出战限制的后门。

如果林地后来确实转为焦土：

**弥烬**：“我原来以为，只要火最后灭了，就算控制住了。”

**岑枝**：“明年这里长什么，再看。”

如果玩家保住了林地：

**弥烬**：“今天没用上的火，倒像是我做得最好的一次。”

**岑枝**：“火留着。晚上冷。”

（对白读取真实环境状态与已执行选择；没有发生烧林就不能播放悔恨分支。自动模式同样按实际行为记录，不另做假剧情。）

## 5. 示例三：旧驿站的两份名册

前提：已找到旧收件名单。记录员在当前驿站，游侠洛恩仅在同地时插话。

**记录员**：“那是旧档。已经没人按它办事了。”

**玩家**：“新档写着全员转移。旧档却有这么多没签收的信。”

**记录员**：“当年的船没来。通知送出去，就算这一站办完了。上面要的是一张填满的表。”

**洛恩（若同地）**：“信没送到，我会再走一趟。你们换了张表。”

**记录员**：“你以为我没回来过？药是我送的，灯油也是。可我没办法让一艘从没出发的船，真的接走谁。”

玩家可以选择：

| 选项 | 当前可见后果 | 不自动发生的事 |
| --- | --- | --- |
| “把事实写清楚。我带副本回去。” | 留下事实记录，后续归航站对话可提到该档案 | 不立刻改变全世界声望，也不凭空完成所有人的撤离 |
| “先问还住在这里的人，他们需要什么。” | 将居民意愿记为后续可询问信息 | 不强制新增一串必做任务，不阻止玩家现在撤离 |
| “我只记录亲眼看见的，旧事暂时不作判断。” | 保留调查进度，递交中性路况记录 | 不自动贴“冷漠”标签或没收正常奖励 |

这段对话允许责任与困难同时存在，不要求玩家只在“原谅好人”和“惩罚坏人”之间选择。

## 6. 示例四：同行短对话

触发建议：洛恩与砾牙在同地安全区域，完成当天某次行动后。可跳过、无额外奖励，不让反复点谈话刷资源。

**洛恩**：“你认识路？”

**砾牙**：“认识味道。”

**洛恩**：“那你为什么跟着我？”

**砾牙**：“你鞋里。有肉。”

**洛恩**：“那是午饭。不是路标。”

另一段可在找到旧信收件人线索后出现：

**洛恩**：“你找的人要是不在了呢？”

**砾牙**：“先找到。”

**洛恩**：“……好。先找到。”

人物关系通过重复出现的小细节积累，不必立刻设计好感等级、羁绊技能或每对角色的完整剧情树。

## 7. 招募之后还能聊什么

建议每名伙伴先覆盖四类短对话：

1. 初次同行：为什么暂时愿意加入，你可以问什么。
2. 地方反应：看到遗迹、焦土、旧路牌或特定天气时的一两句感想。
3. 个人线索：一封信、一处药物送达或一个旧营地，把人物动机带回当前地图。
4. 选择后的回访：根据玩家实际做过的事情改变回应。

谈话并非每次都发任务。可以有玩笑、习惯与沉默，也可以让角色说“我现在还不想讲”。长篇身世优先拆成有触发条件的片段，避免初遇一次倒完。

## 8. 首轮叙事范围与一致性检查

多支线、多分支与多结局是已确认方向。原六名伙伴初遇与六类探索题材保留为素材，不再限制剧情长度与分支数量。首章、六人个人线和未撤离结局由专职剧情稿细化，主 agent 审查因果、互斥、物品来源与已设计路径，不以换台词代替真实后果。

角色可直接同行、任务后同行、战后结识，玩家均可拒绝；帮助但不同行与拒绝帮助是不同结果。到站不自动结束，可等同伴或继续管理探索；主动确认结束时，已加入但异地未撤离者按伤势、个人线和选择给出对应剧情，不自动死亡，与未加入 NPC 分开记录。

任务原件由个人携带、同格交接，不能凭共享地图远程提交。已探索格永久点亮可观测，但结局只依据结束当时状态及有来源的后续消息，不预知离开后的未来，也不借剧情免费治疗、传送或增加终结技充能。

后续审稿时检查：

- 不招募任何指定角色也能理解基本撤离目标，不完成剧情也可以撤离。
- 人物发言与在场状态一致，没有异地参战、隔空施法、远程队伍加成或资源自动交接。
- 玩家提早离开时有完整回应，不以隐藏主线条件阻止撤离。
- 同一选择的对白、地图状态、资源和结算记录一致，读档不会重复发奖。
- 主角和伙伴都受角色属性约束，叙事中的“主角”不是规则之外的指挥光标。
- 战斗只推进当前战场环境，不能通过一段对白让远方村庄因战斗经过了数天。
- 当前仍处于设计阶段；采用世界观与剧情不等于开始编码、配音或批量生成肖像。
