# 叙事与对话

本文件描述《维洛丹》的现行对白。角色经历与分支文本以 `game/scripts/domain/narrative.gd` 为准，节点以 `game/assets/story/node_events.json` 为准；不再采用旧归航站、名册调查和六人撤离故事。

## 说话是为了眼前的事

初遇先让玩家听见对方的态度和当前关注，不把人物档案整段念出来。加入以后可以单独询问过去、谈下一步打算、回顾已作的决定。普通闲聊不自动拼接身世、结局和主角身份暗示。

每句话应回答三个问题：对谁说、为什么现在说、希望对方做什么。隐瞒、炫耀、求援、试探和讨价还价都可以成为动机。反派不会仅为让玩家知道设定，主动交出足以害死自己的秘密。

文本区分人物对白、旁白和行动结果。奖励、资源消耗和存档提示由界面说明，不让村民反复声明两个办法酬劳相同。正文过长时按页点击阅读，选项在正文最后一页出现，不重复播放同一段介绍。

## 人物有不同的做法

- 洛恩的信使经历用来穿过封锁、寻找援手和带人脱困，不围绕抄停火信决定该公开谁的名字。
- 医者面对伤员、护卫、药物与助手的选择；救治敌人不等于有能力让整支军队停战。
- 工匠会争炉子、材料、人手和施工办法；地图可以指导施工，却不能通过多一个签名自动消除危险。
- 掌兵的人考虑守哪里、放谁进城、谁听号令。有些人保护别人，有些人保住自己的地位。
- 恶魔可以谈价、守约、欺骗条款以外的人；不把收取约定报酬写成必须反省的过错。
- 神可以答应、拒绝、迁怒或改变主意。祈祷来自真实的困境，而不是供神审核的一叠格式相同的文书。

并非所有支线都要打仗。生活、玩笑、照料、买卖和独处同样能推进人物。书信、军令和契约也可以出现，但必须有用处，不是所有矛盾的统一解法。

## 玩家选项与后果

选项是当前来访者说得出口的话，不强制用“我”开头。NPC受邀担任守将，玩家可以劝其接受或拒绝，不能替NPC说“我来接这个职位”。

两条分支要有不同的行动方向和代价，不能只在公开或封存同一份纸之间打转。选择后的回应只描述现场发生的事、人物的态度和准备；尾声也不能未经行动就宣布援军已到、村庄已救或失踪者平安。

现有个人抉择不发额外资源、不改变位置和战斗，不凭对白执行招军、攻城或建造。新选择保存为 `journey_a` / `journey_b`，已完成的旧选择保留原来的事情与结果，不把旧档里抄信的选择偷换成已经决定招兵。

## 场景与交谈边界

交谈要求双方同地且能行动，个人抉择还要求已加入、处于安全探索。重伤、战斗待处理或异地时不能继续作决定。普通伙伴不能替缺席主角触发身份暗示。

日常对白不能突然提起没有交代的“那把弩”或“那个病人”。已经选过的故事通过回顾入口阅读，不和新的开场硬拼在一起。重读不改选，不重复给奖励。

## 节点与器物

亡灵事件先弄清牵挂和生死，再告别。可用现场目击、亲属熟悉的细节、遗物和口头交谈，不要求每次都核对家书。普通伙伴可以调查，但引渡仍要求健康的旅人在场。

委托的两种行动在当地可做，工具和材料有来源。描述具体改变，不在每段结尾机械补一条免责说明。取走物品要有合适来历，但不用把每个箱子写成一次产权审核。

器物故事讲来历、经历和留下的痕迹。功能说明负责准确写出数值和条件，故事不反复声明“不是神迹”“不能代替人走路”。物主可以慷慨、吝啬、好胜、怯懦或贪财，不必每件遗物都留下同一条劝善格言。
