# MVP 实现取舍与测试参数

更新日期：2026-11-04。用户已授权开始开发，并要求开发结束前由 agent 自行决定剩余事项，不再逐项确认。本记录维护实现选择，不能覆盖已确认规则。

## 已新增确认

双方同时全部倒下且无合格候补时，按战败处理。主角参与则远征失败；主角未参与则该队留在遭遇地点待援。不能先套敌方全灭胜利，再免费恢复己方。

## 本轮默认实现规则

| 事项 | 选择 |
| --- | --- |
| 行动条 | 初始间隔为 1000 / 速度，行动后重新计算间隔；同时间按稳定角色标识排序 |
| 换人/补位 | 换入者从当前时刻等待完整个人间隔；手动替换消耗换出者当前正常行动；全部倒下时依合格同地候补补位 |
| 候补安全 | 未上场者不承受战斗单体/群体或火场伤害；首次上场支付一次参战费，返回不重复收费 |
| 终结技 | 单次攻击指令按一次充能，多段不额外刷能；终结技自身不充能，间隙请求按 FIFO 结算，仅在场存活者可用；能量隔日保留 |
| 自动战斗 | 只替换战斗决策，共用规则；优先有需要的治疗、合法技能、缺魔时普攻；普通技能与终结技按现有环境条件点燃森林；不自动使用个人消耗品或撤退 |
| 战斗并发 | 单场战斗期间暂停地图操作；动画时间不推进日期或异地环境 |
| 火伤 | 战斗每 10 行动时间单位、在原子行动后同时结算在场双方各 8% 最大生命；不消耗森林燃料 |
| 日环境 | 下一日天气先确定；雨天先灭火，不消耗燃料；晴天原火场燃料每日减 1，仅快照中的原火场传播一次，新火场同日不继续扩散 |
| 战斗外主角重伤 | 不单独判失败，健康伙伴仍可实际同地救援；全远征队均重伤才失败 |
| 搬运 | 本轮先用实际同地物资/治疗救醒后移动，不加入重伤搬运系统 |
| 撤退 | 已出战存活者损失最大生命 10%，不返 AP/物资，不触发胜后 1 HP；前置移动者返回来源格，原地事件交战不位移 |
| 装备 | 战斗外可行动角色免费装备/卸下持有装备，不改变当前 HP/MP/AP；武器、防具、饰品各一栏，暂不改整套人偶服装 |
| 营地 | 安全、非焦土地块建造 2 AP + 2 木料，至多两处；只恢复实际执行休整的角色，不含异地队友或自动生产 |
| 休整 | 安全地点消耗 2 AP，恢复 HP/MP 各 20%，有效营地为 30%；雨天森林减 5 个百分点，同地健康伊芙加 10 个百分点；重伤不能自行休整 |
| 角色专长 | 岑枝森林采集多一份；洛恩山地移动 1 AP；伊芙改善同地休整；砾牙能辨识已发现的邻近敌人详情，在场健康时保护生命低于 35% 的其他队友、减伤 20%；弥烬与澄汐可在地图使用本人的水火技能 |
| 砾牙终结技 | 群山长鸣为当前场上队友增加 45 护盾，不设为纯伤害技能 |
| 交接界面 | 单行只显示“交接”，再选择同地接收人，每次一件；全员同地时也不横向堆叠六个按钮 |
| 资产技术 | 原创程序化 3D 模型用真实 Skeleton3D/BoneAttachment3D 连接部件并驱动基础骨骼动作；探索、战斗共用模型代码与材质，四足单独骨架 |
| 字体 | Noto Sans SC，可变字重字体随工程分发，OFL 许可随附 |

## 首轮测试值

- 三个职业模板：巡路客（9 AP）、守灯卫（5 AP）、烛纹师（7 AP）。伙伴 AP 分别为岑枝 8、洛恩 10、伊芙 7、砾牙 6、弥烬 5、澄汐 7，没有统一 AP 基准。
- 普通移动 1 AP，山地/沼泽 2 AP，洛恩山地减为 1 AP；每人每场首次上场 2 AP，真正伏击预算不足扣到 0。
- 每日可行动者恢复最大 HP 的 16%、最大 MP 的 22%，向上取整，不扶起 HP0；重伤者同样重置自己的 AP，但仍不能行动或自行恢复 HP/MP。疗伤药恢复 45 HP，澄露恢复 30 MP。
- 普攻充能 25，伤害技能 30，治疗/护盾技能 20，防守 10；上限 100，终结技用后清零，战后保留剩余量。
- 森林燃料 3 天，浸湿覆盖 2 天。属性、地形与天气倍率总乘积限制在 0.5～1.5。
- 出生点与撤离点六边形距离至少 12，地形加权路径成本同时至少 12；早期直接同行者位于三次合法移动内。固定种子决定合法位置，六名伙伴每局各一次。
- 首轮内容按已有候选实现八类普通敌人、两类精英和可选旧驿灯卫；首领不能占关键任务/撤离通路，不作为撤离钥匙。

这些是可调整的 MVP 参数，不是最终平衡。完整验证及其边界见 [验收记录](acceptance-report.md)，阶段情况见开发进度。

## 实际工程组织

`game/scripts/domain/` 管理集中定义、六边形生成、远征状态、战斗和有限剧情解释器；`game/scripts/presentation/` 管理共用骨架、人偶、地形、视图与合成音效。`main.gd` 负责原生界面和操作编排，`scenes/main.tscn` 为入口。当前体量采用少量集中模块，未机械拆出原计划中的全部空目录。

存档在稳定行动后写入，临时文件替换并保留 `.bak`；保存 64 位 RNG 字符串，加载时验证必要字段、资源、坐标、装备持有状态及遭遇检查点。战斗仅保留收费前检查点，继续时重新进场。语音、复杂过场、永久成长和实时生成对话不进入此版。

Godot 与第三方声明通过 `tools/export_licenses.gd` 从当前引擎提取；API 来源为 [Godot Engine 官方说明](https://docs.godotengine.org/en/stable/classes/class_engine.html#class-engine-method-get-license-text)。画像提示词、Noto OFL 和资产来源随仓库保存。
