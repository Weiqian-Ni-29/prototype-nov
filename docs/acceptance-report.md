## 图形与运行包

源码和导出包均使用原生窗口，在本机 OpenGL 驱动上实际启动。桌面操作检查菜单/职业、开始、选格与逐人费用、信使对话和同行、背包/装备/技能说明、保存继续。图形夹具逐一渲染所有基础战场，覆盖四足、蜘蛛、蜂群、构装与人形骨架。

Windows release 模板导出内嵌 PCK 的独立 EXE。便携包附指南、Godot/第三方声明、Noto OFL 和 `build-info.json`（引擎版本、源码提交、文件 SHA-256）；旁置 ZIP SHA-256。导出包启动验证单独执行，交付包和检查日志随本地交付提供。

## 本轮发现并修复

- 界面信号内立即释放自身导致错误：改为先移出树，再延迟释放，并加入原生按钮回归。
- 四人战斗面板被日志区遮住：调整血条、间距与滚动边界，检查友方决策窗口的技能说明。
- 载入 JSON 后数值类型与顺序改变：按序列化语义验证，保留精确 RNG；交接检查按真实物品行选择，不假定首行物品。
- 自动战斗使用火技破坏保林故事：加入可见策略开关，普通火技与终结技统一遵守保林选择。
- 七人同地时物品行横向堆满接收人：采用单个交接入口与独立选择面板。
- 雨天先消耗燃料、重伤日结算资源等时序边界：统一明确顺序并补充断言。
- 未加入的普通战斗对手不能套用友方胜后免费恢复：必须实际同地救援后再谈同行。

## 限制

这是功能性 MVP：程序化立体模型与基础骨骼动作、短音效和生成肖像用于验证方向，尚无复杂过场、配音或商业级角色动作。数值完成首轮可玩性验证，尚未做外部玩家平衡测试。仅本机 Windows x64 / Intel Iris Xe 实测，未宣称所有随机种子、硬件、分支组合或长时间运行均无缺陷。仅局内单槽存档，战斗恢复到战前稳定点；其他平台、跨局养成、联机及运行时 AI 对话不属于本轮。
