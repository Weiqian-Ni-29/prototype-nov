# MVP 开发进度

更新日期：2026-11-05。版本：MVP 0.2.0。分支：`dev/mvp-expedition`。

## 当前成果

- M0～M1：原生 Godot 工程、217 格六边形、六类地形、合法随机相遇、共享永久探索、独立位置/AP、背包和三槽装备已完成。
- M2：连续速度条、手动/自动、个人终结技插队、同地四人/候补、一次参战收费、伏击、重伤救援、撤退与胜败闭环已完成。
- M3：日恢复、天气预报、水火、有限燃料与六邻快照传播、物理证物及剧情切片已完成。
- M4：三种职业、六名伙伴、八类普通敌人、两类精英和可选首领；首章与六人故事、7 个主线结局、24 个个人结果、24 类异地尾声及交叉修饰已接入。
- M5：探索与战斗共用的真实 3D 骨架人偶、简单动作、手绘质感沙盘、六类战场/天气环境、十张原创二次元肖像、合成音效、原生中文界面与稳定存档已完成。
- M6：本机整体回归、三职业真实完整旅程、真实战败、图形及界面验证已完成；Windows 便携包在交付时单独运行验证。

## 当前验证

规则、故事、整局、边界、原生界面及图形检查由 `python tools/run_checks.py --visual` 统一运行；引擎即便返回 0，只要出现脚本错误或资源泄漏，检查也判失败。

三条完整成功旅程分别为种子 20261104 / 巡路客、41 / 守灯卫、918 / 烛纹师。均实际逐格移动、招募全部六人、处理原件与支线、分头调查、共同战斗、到站后继续行动、存档继续，再主动撤离；没有传送或测试补给。另有种子 77 的真实主角战败。准确数量、覆盖边界、修复记录见 [验收记录](acceptance-report.md)。

## 交付与后续

交付物为 Windows x64 便携包、指南、许可、校验清单与测试记录；代码通过开发分支和合并请求审阅，不自行合入主分支。最终交付位置和 MR 链接在交付消息中提供。

此版达到约定 MVP 功能范围，不代表正式发行：美术与基础骨骼演出仍为原型规格，尚无外部玩家的平衡结论，也未验证其他硬件/平台。后续依试玩反馈调整数值、操作便利性、演出与内容量。实现取舍见 [实现记录](implementation-notes.md)。
