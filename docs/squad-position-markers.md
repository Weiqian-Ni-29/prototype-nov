# 小队拆分与位置标记

## 玩家操作

- 左栏同一彩色边框中的角色属于一队；点角色或地图上的同色向下箭头选中该队。点相邻地块预览移动，再点同一格确认，即使目标格已有其他小队也不需要先点脚下地块。选中箭头增大并显示亮色描边，不显示数字。
- 在「行动」界面选择「拆分小队」，勾选一个或多个成员组成新队。原队须留至少一名成员；拆分不消耗精力。
- 主动拆分后，两队可留在同一格，各有箭头和左栏边框。刷新界面、切换选择、存档重载不会重新合并。
- 队伍移动到有其他队伍的格子时自动合并（包括该格多个分队），沿用驻留队伍中最早创建队伍的颜色。
- 战斗撤退先拆出实际移动者，未移动的驻留队保留原颜色；撤退回到有人驻留的原格也按抵达规则合队。撤退后选择与读档恢复均使用新的队伍成员。
- 整队移动保留颜色；仅勾选部分成员出发时，该部分另成一队。默认选择整队可行动成员；重伤者保留所属队伍，但不默认勾选移动。
- 同格箭头横向错开并连接实际位置，缩放不改变屏幕尺寸，绘制在树冠上方、HUD下方。远景重叠时避让；菜单和战斗中隐藏。

## 数据与兼容

新增 `actor.squad_id`、`data.squad_colors`、`data.next_squad_id`。沿用存档版本 2 的可选字段扩展；旧档按同格迁移，新档保存显式分队。扩展字段不合法时拒绝载入，不覆盖旧存档。

颜色使用预置蓝、粉等调色板并按新队编号延展，不设置队伍数量上限。大量颜色在人眼上的可辨性存在天然上限，本次按确认的纯色方案不增加数字或文字编号。
