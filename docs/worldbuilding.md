# 维洛丹的世界与人物

现行故事见 [故事大纲](story-outline.md)，角色与节点见 [剧情分支](story-branches.md)，对白规则见 [叙事与对话](narrative-dialogue.md)。早期《归灯之野》、灯路和归航站设定已被替换，不再作为当前剧情依据。

## 战争中的生活

城邦为粮食、河道和矿山交战。普通人可能投军、逃难、守家、做买卖，也可能趁乱报仇。神明会回应祈祷，却不保证按求助者的心意施恩。某地求来的严霜能挡住兵车，也可能毁掉邻谷的庄稼。

亡者无法离开现世，挡住道路、水源和房屋。人们起初只能看见这些后果，并不知道死亡之神遭到了什么事。四座大神殿的钟声没有让所有亡者安息。

开场先讲维洛丹过去的生活、各个种族和四位人们熟知的神。接着讲诸神开战后，封路如何让村子缺粮，死去的人又为什么让家人害怕。旅人在村里醒来后，玩家会从同行者的经历和旅人的记忆中知道更多。

## 种族和立场

人类、矮人、精灵、龙、恶魔与神共同生活在这个世界。龙和恶魔能够化作人形；三位可同行的神使用化身。化身受伤不等于神被杀死，也不意味着普通人认识神的真容。

恶魔交易所索取的东西可以是财物、记忆、要塞或权力。履行约定不必引出良心谴责；合作也不等于善良。契岑重视约定本身，弥烬看重自己的火与价码，灰角想控制握兵的人，闻霆在意别人能否胜过自己的雷术。

其他种族同样有不同立场。有人护短，有人争权，有人救治敌人，有人为了本族出卖盟友。角色应有愿意做和不愿意做的事，不以每人都承认错误作为成长的终点。

## 四场相互牵连的旧战事

- **黑旗围城**：黑旗军围攻王城，守军、龙和恶魔从不同方向介入。有人冲破封锁，有人拿俘虏开路，有人贩卖消息。
- **封河之战**：船工求来的一夜静风被军舰冒用。莱文索让风暴再起，河岸的人还要面对封锁、洪水与断桥。
- **断山之役**：城邦挖穿承重岩层，又求多兰克拦住敌军。山道断裂，工匠、守军和逃难者争夺剩下的出路。
- **霜谷饥荒**：梅文娜提前降冬杀虫，粮仓得以保住，邻谷的庄稼却遭了霜。军队拿粮招兵，村落各自设法过冬。

这些是伙伴的亲历背景，不代表随机地图上的每个节点都已发生同一场战斗，也不自动授予玩家兵力或据点。

## 死亡之神与战神

以下涉及终战揭晓。

伊文洛负责死亡与亡魂引渡，重力也是他的权能。卡德兰以商谈停战诱他赴会，摧毁其肉体，观察到引渡停止后误信他已彻底消失。卡德兰通过活人的疯狂与纷争变强，不能指挥亡兵继续作战。

重生是伊文洛自己原先也不知道的特殊性，不是预设的后手。身体在冥界重新长成后，一次为逃难者求援的恶魔召唤意外将昏迷的他带到现世。村民救下他，此后他以旅人的身份上路。

冥河属于冥界，能洗刷、剥夺和吞噬一切，不会识别敌友。最终战中伊文洛控制河界，让同伴留在岸上。普通技能、装备与遗器不因此获得创造冥河或引渡亡魂的能力。

击败卡德兰并恢复引渡后，诸神能够停战。城邦的争端、毁坏的家园和失散的人仍在，不把一场胜利写成全世界从此没有战争。

## 地图与叙事边界

地图的地形和地点由种子生成。故事不让远处地块凭空变化，也不代替实际移动、战斗、治疗和奖励结算。伙伴个人抉择记录态度与下一步打算；尚未执行的救援、集结或建设不能写成已经成功。

重新开始远征是游戏流程，不设角色记得每次失败的时间循环。当前没有通过一段对白直接操作的大军征募、攻城或工坊建造系统。
