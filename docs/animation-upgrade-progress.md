## 观感、录像与性能

已保存相同样板升级前后 15.37 秒原生录像和四类动作截图，另有 34.9 秒真实技能演出录像、剑尖接触帧、七类地貌、全角色、迷雾海岸、全图与两种分辨率压力截图。演出实机固定帧录像为 30 FPS，不用于声称实时帧率。KayKit 1.0 的三人形八动作也在相同镜头实际比较，未作为运行资源发行。

Windows x64 / i7-1260P / Intel Iris Xe / OpenGL Compatibility。四场各 300 帧：平均 59.99～60.01 FPS，P95 16.727～16.865 ms，最慢一帧 34.605 ms。关闭垂直同步后的原始吞吐为 137～180 FPS；本版使用 60 FPS 上限，避开本机 Intel 驱动半刷新率等待。全图静态地景已合并；没有关闭全部特效换取数字。不是对其他硬件或长时间游玩的性能保证。
