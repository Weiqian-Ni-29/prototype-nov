# 动画与地景适配说明（MVP 0.2.0）

日期：2026-11-05。目标分支 `dev/mvp-expedition`，引擎 Godot 4.7.2 / Compatibility。玩法与故事规则沿用 MVP 0.1.0；新增领域数据仅为已经结算的只读呈现元数据。

## 素材选择与实机比较

审查入口、精确压缩包 SHA-256、原始许可、文件清单和修改说明分别保存在 `game/assets/characters/sources.json`、`game/assets/nature/sources.json` 及 `game/assets/licenses/`。模型及动画的免费层为 Adventurers **2.0**、Character Animations **1.1**；粒子压缩包实际标注 **1.1**，不以网页旧标签替代原包版本。Forest Nature Free **1.0** 为本次地景追加。所有接入外部美术为 CC0，允许本商业游戏和公开源码分发；没有新增外部脚本或音频。狼的作者是 **crownjoshua**，不是 Quaternius。

Quaternius 当前 QAL 的原始素材再分发条款不适合本公开仓库，未接入。KayKit Adventurers 1.0 作者公开提交 `672074b73ba276876a19e8816ecdc5241817ab47` 也做了实机比较：相同战场、灯光、1280×800，相同位置加载 Knight/Rogue/Mage，实际播放八种动作；有 75 个源动作（Godot 加 RESET 显示 76），但无专用弓拉弦/放箭组，也没有新版 Ranger。比较入口 `tests/compare_candidates.gd -- --source=<已核验的本地解压目录>`，旧库不进入运行包。

## 可复现资产处理

正常克隆已经包含必需 GLB/glTF/PNG 与原始许可；运行游戏不需要 Blender 或下载账号。重新制作资产时自行取得清单中同版本的作者免费压缩包，再执行：

```powershell
python tools/prepare_character_assets.py --assets <下载目录>
blender --background --factory-startup --disable-autoexec --python tools/build_creature_assets.py -- --assets <下载目录> --all
python tools/prepare_nature_assets.py --assets <下载目录>
godot_console --headless --path game --script ../tools/prepare_bone_map.gd
godot_console --headless --path game --editor --quit
```

Blender 实际使用 4.5.15 LTS；读取旧狼 `.blend` 时禁用自动脚本，不执行包内代码。各工具首先验证已经审查的 ZIP SHA，输入变化会失败，升级版本须重新核验许可。人形工具检查模型与五个动作库的静止姿态，最大误差约 `9.33e-13`（超过 `0.0002` 拒绝）；匹配骨架不需要人为扭曲静止姿态。统一 23 个骨名，使用 `SkeletonProfileHumanoid` / BoneMap；没有的颈、肩、指骨不伪造。四足、蜘蛛、蜂群采用独立骨架，不强套人形 Profile。

每个人形包含 19 个选取片段：idle、walk、run、attack_melee、attack_heavy、bow_draw、attack_bow、cast、support、channel、guard、hit、down、item、rally、crossbow_aim、crossbow_shoot、bow_draw_up、bow_release_up。片段来自同作者免费库，水平根位移已剥离。`recover` 只在真实 HP 状态变化时逆播当前倒下片段，不借动画复活。狼、兽、蜘蛛、蜂群各有 13 个本项目制作片段；狼重建干净 FK 绑定、镜像、最多四权重归一化，动物步态用离线 FABRIK 烘焙着地点。

## 运行时呈现边界

- `doll.gd` 只负责选择、位移队列和状态包装，`rigged_doll.gd` 的 AnimationPlayer 独占骨架；不再同时逐帧写骨骼。地图按实际移动速度调整原地步行/跑步片段，连续点击保留中间格，不重扣 AP。
- 近战从原阵位接近真实目标。提前采样所选挥剑动作的剑尖前伸及目标高度，命中时短停、跟进并退回；身体呈现偏移不会写入六边形位置。弓/弩/法术原地发射，不统一冲锋。
- 每条领域事件有稳定 ID、技能 ID、实际目标、HP/护盾/MP 前后结果与环境快照。队列深拷贝并去重，只回放一次；自动战斗与额外终结技继续由领域层结算。浮字使用实际差值，辅助目标不播放挨打，施法者不被自己的目标反馈覆盖。
- 治疗、护盾、箭雨、火、水、声波及七种终结技具有不同动作/效果。普通攻击仍为普通属性。弩手实际蓄力时维持瞄准姿态。镜头反馈幅度短且在退出时清零；声音为本项目 PCM 合成，四声部避免点击立即切掉效果。
- 点燃和浸湿只更新本场战斗的环境舞台，保留角色及其动作。地图地形与迷雾各自独立渲染。倒下保持，加载重伤直接显示终态，救援后才起身。

## 地景、海域与性能

陆地仍为半径 8 / 217 格。蓝色海格位于岛外五圈，使用一个 MultiMesh 和远海平面，带浅深过渡、水纹和碎浪；没有加入领域地块或路径图，不能点击走海，也不揭开未知陆地。土地使用倒角、土层和纸纹式着色，十三个自然模型以统一低饱和材质呈现；遗迹残破形式、芦苇、浮叶和沙纹为原制作。探索和战场复用这套地貌资产。

全地图点亮时，静态地景按材质合并，粒子、标签、角色仍独立，只有地块/迷雾变化才重建合并网格。实机曾观察到 Intel OpenGL 垂直同步降至约 30 FPS，关闭垂直同步后吞吐量为 137～180 FPS，最终使用 60 FPS 上限保证本机节奏。没有用录像帧率宣称实时性能。

验收设备：Windows x64，Intel Core i7-1260P / Iris Xe，Compatibility。300 帧/场景，默认 60 FPS 限制：

| 场景 | 分辨率 | 平均 FPS | P95 帧时 ms | 最慢帧 ms |
| --- | --- | ---: | ---: | ---: |
| 点亮 217 格 + 七人同地 | 1280×800 | 59.99 | 16.820 | 34.605 |
| 四友方/四敌方 + 雨/火/群体盾 | 1280×800 | 60.01 | 16.750 | 20.121 |
| 点亮 217 格 + 七人同地 | 1440×900 | 60.00 | 16.865 | 23.517 |
| 四友方/四敌方 + 雨/火/群体盾 | 1440×900 | 60.01 | 16.727 | 17.226 |

四场合计 1200 帧，只有一帧超过 33.34 ms；不能据此保证所有硬件、驱动或长时间运行都稳定 60 FPS。雨火叠加为渲染压力夹具，不代表雨天能依规则点燃森林。完整自动化与发行检查见升级进度记录。

## 当前表现限制

保持桌游低模人偶与短动作，不是高精度人体或电影过场。不同装备尚不逐件替换外观；阵位不做物理碰撞，群体重击沿用原范围，视效不增加位移或重复伤害。只验证 Windows x64 / 本机显卡；其他平台、配音、复杂表情及玩家平衡评估不属于本次范围。

源人形动画以 glTF 关键帧时间采样，常规片段为约 1/30 秒步长；本项目动物动画按 24 FPS 烘焙。人形发布 GLB 为每个约 0.89～1.03 MB，原贴图嵌入，武器使用原 PNG 图集；自然 glTF 使用共享 PNG 图集。旧 1.0 原包人形约 3.66 MB/个，保留 41 骨/75 动作，不进入发布包。帧时间以运行时速率和实际输入关键帧为准，不假定所有片段时长相等。
