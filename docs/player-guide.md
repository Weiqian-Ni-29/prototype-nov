# 维洛丹试玩指南

在主菜单点「开始新远征」直接阅读开场。想重玩同一张地图，可以先在「地图种子」里输入相同内容。留空时每次出发随机生成，当前种子记在旅途手记里。村民送来的药品、澄露、干粮和装备会随出发一起写进存档。

点击对白右侧的提示或故事画面的空白处推进。选项在相关情节讲完后出现。角色说完来意后可以提出同行。可能进入交战的选项有单独的确认步骤。

点击邻格预览消耗的精力，再点一次确认移动。左侧可勾选同地同行者，也可切换小队。每场战斗最多四名己方角色同时在场。终结技在充能达到 100% 后可额外释放。

「行动」打开脚下地块。商店使用全队的灯铢，购入物品进入实际交易者的背包。歇脚节点一次只选择一项恢复或物资奖励。结束一天补足精力，生命和魔力靠补给、治疗与歇脚节点恢复。

探索度达到 20%、40%、60%、80% 时依次推进剧情。80% 后可从旅途手记定位战神。旅人要亲自到场并保留 2 点精力参加决战。击败战神后，游戏会播放结局和遇到过的角色尾声。

《维洛丹》使用新存档目录。此前故事的存档仍留在原来的目录中。
