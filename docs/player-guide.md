# 维洛丹试玩指南

在主菜单点「开始新远征」直接阅读开场。想重玩同一张地图，可以先在「地图种子」里输入相同内容。留空时每次出发随机生成，当前种子可以在「设置/帮助」查看。村民送来的药品、澄露、干粮和装备会随出发一起写进存档。

点击故事画面的空白处推进，也可按回车继续。较长正文自动拆成多页，不需要鼠标滚轮；可用“上一页”回看当前段落，选项在相关情节全部读完后出现。主线结局和伙伴尾声也按同样方式逐页阅读。角色说完来意后可以提出同行；加入后，同地交谈可主动问过去或商量接下来的打算，先读完整段话再作选择。已作出的决定通过单独选项回顾，不在每次闲聊时重播。失忆旅人还可向某些角色询问是否认得自己，普通队员没有这个话题。决定保留在存档并影响个人尾声，不能重复改选；异地救援、招人和修建仍是角色接下来要去做的事。可能进入交战的选项有单独的确认步骤。

点击邻格预览，再点一次确认。地图上由旅人带队，伙伴随行。山路和平地每格都记一步，走满五步自动进入下一天。远征队顶部的五段绿色精力条显示全队今日还能走几步。走一格就淡掉一段，换日后重新点亮五段。

在地图左侧点「卡组」，也可在开战前编辑。卡片可按名称、效果、类型和元素筛选。开战需带满 12 张，每位伙伴限带一张，其余卡每种限两张。招募伙伴后会解锁对应的卡牌。

双方主战者从 3×4 棋盘各自中路后排开局，先各抽三张牌，之后每次轮到自己抽一张。每回合只能走一子、部署一位伙伴或打出一张武器、防御、法术牌。部署只可选己方半场的空格。主战者横、竖、斜都能走一格，伙伴的走法和特性可查看卡面。点击棋子或手牌后，棋盘会高亮可选目标。

攻击先扣护甲再扣生命，击倒目标后才能占领它的格子。火和水的伤害随晴雨变化。牌库耗尽后，每次抽牌会给本方全体在场棋子造成递增的疲劳伤害，从 1 点开始，每次加 1。击倒对方主战者即胜利，己方主战者倒下则远征结束。

「行动」打开脚下地块。商店使用全队的灯铢，购入物品进入实际交易者的背包。补给点只可领取一次物资。探索途中可以消耗补给来疗伤、回魔或救援。换日会刷新天气。

亡灵节点先调查，再选择告别方式。其他队员可以问清经过，需要健康的旅人来到同一格才能引渡。委托也有两种处理方法，选择不同结语，每处只支付一次酬劳。

探索度达到 20%、40%、60%、80% 后，在选中健康旅人并继续探索时依次阅读主线现场遭遇。读完第四段后，地图顶部会显示「定位战神」。旅人要亲自参加决战。击败战神后，游戏会播放结局和遇到过的角色尾声。

《维洛丹》使用新存档目录。此前故事的存档仍留在原来的目录中。
