# 《归灯之野》MVP 0.1.0 试玩指南

Windows x64 便携版。解压整个文件夹，双击 `ReturnToTheLamps.exe` 即可游玩，无须安装 Godot、Python 或额外运行库。已在本机 Intel Iris Xe / OpenGL 上验证；其他硬件尚未做兼容性验证。

## 开始一局

选择巡路客、守灯卫或烛纹师，再点击“开始远征”。地图种子可修改；首次推荐保留 `20261104`。新远征会替换单槽存档。

目标是找到远处的归航站，让主角到站并主动确认撤离。没有天数限制，可以等待同伴，也可以主动放弃本次远征。

## 地图与角色

- 点击左侧角色可选中并定位；勾选同一地块的成员可共同移动。点击相邻地块，再在右侧确认“前往此格”。每人分别支付自己的 AP。
- WASD 平移，滚轮缩放。角色揭开所在格与周围一圈；全队已探索区域一直可观察。
- 普通移动 1 AP，山地、沼泽 2 AP；洛恩走山地为 1 AP。AP 不够时可选择其他角色或结束一天。
- “结束一天”统一推进日期，每个人 AP 回到个人上限，可行动者恢复部分 HP/MP。生命为 0 的重伤者需要同地队友用药或治疗，不能等次日自行站起。
- 每人拥有独立背包，不限容量；同地免费交接。武器、防具、饰品各一个槽位，背包面板也列出属性、技能和专长。
- 交谈、同行与交付任务免费。角色可能直接同行、完成任务后同行，或在普通战斗后需要你实际救援。可以暂缓或拒绝。

## 战斗

- 同地最多四人同时出战，首次上场每人支付 2 AP；候补上场也付一次，同场返回不重复扣。伏击时不足部分扣到 0。
- 连续速度条决定行动先后和频率。先点右侧敌人，再选择普攻、技能或防守；辅助单体技能会要求选择队友。
- 普通技能消耗 MP。战斗攻击、辅助与防守为本人充能；地图采集不充能。
- 左侧满能量按钮可以申请终结技，当前原子动作结束后额外释放，清空能量但保留正常行动。终结技包括伤害、治疗和护盾。
- 只有本人正常行动时能用其背包的恢复物资，可用多件，用后仍可攻击或施法。
- 换人占一次正常行动，只能换同地合格候补。“自动”可随时切换；默认“自动保林”，开启“自动可点火”后才允许自动使用会点燃干燥森林的火系技能和终结技。
- 撤退不退还 AP 或已用物资，已出战者承受 10% 最大生命损伤；前置移动者退回来源格。

开阔地可提前查看部分敌人；森林、沼泽的异动可能是伏击。敌人强度固定，独行前注意危险提示。生命归零不立即结束整局：胜利后本战倒下的友方恢复至 1 HP；主角参与且候补也无法继续时才判失败。主角不在的败队留原地待援；全队失能也会失败。

## 环境与故事

火焰可能点燃当前森林，水术可灭火并留下潮湿。战斗只处理当前战场；森林燃料和六邻蔓延在日结算处理。雨天先灭火。地图、战场和后续剧情保留实际后果。

六名伙伴每局都在合法地形中出现，位置随种子改变。沿归航方向可找到旧驿站、林边住户和记录点；“旅途手记”记录已接触人物、原件持有人以及已发现归航站的位置。

文书需要由实际持有人到场交付，共享地图不会传送物品或代替 NPC 授权。故事存在拒绝、隐私、分歧和证据不足的结果；调查和首领战都不是撤离前置条件。你到站后可以继续行动，最终确认前会列出到站者和异地成员。结算会按实际伤势、位置及个人故事给出尾声，异地未撤离不等于自动死亡。

## 存档与退出

重要操作自动保存，也可以点击顶部“保存”。关窗后从菜单“继续上次远征”恢复。战斗中保留战前检查点，继续时重进同一遭遇，不保存半个动画或重复发奖励。

存档位于 `%APPDATA%/Godot/app_userdata/归灯之野 · 白栎远征/expedition.json`，前一次文件保留为 `.bak`。设置音效音量也会记住。此版为单槽局内存档，没有跨局永久成长。

## 版本范围

包含半径 8、217 格地图，三种职业、六名伙伴、八类普通敌人、两类精英、一个可选首领、完整首章分支，以及共用 3D 小人偶和基础骨骼动作。美术和演出属于 MVP 规格，尚无配音、复杂动作、联机或商业版内容量。原画、程序化资产与音效来源见仓库；Godot、第三方组件与 Noto 字体许可在 `licenses/`。
