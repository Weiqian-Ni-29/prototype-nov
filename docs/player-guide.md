# 《归灯之野》MVP 0.2.0 试玩指南

Windows x64 便携版。解压整个文件夹，双击 `ReturnToTheLamps.exe` 即可游玩，无须安装 Godot、Python 或额外运行库。已在本机 Intel Iris Xe / OpenGL 上验证；其他硬件尚未做兼容性验证。

## 开始一局

在主菜单点击“开始新远征”，再选择巡路客、守灯卫或烛纹师。右侧立绘随职业切换。地图种子可修改，首次推荐保留 `20261104`。

点击“开始远征”进入剧情。从右下角选择旅人的回应或行动，走出废棚后才会创建新存档。剧情右上角可返回职业选择或跳过。本版使用新的存档版本，从旧版升级时请开始新远征。

目标是找到远处的归航站，让主角到站并主动确认撤离。没有天数限制，可以等待同伴，也可以主动放弃本次远征。

## 地图与角色

- 点击地图上另一支小队所在的地块可切换小队，也可点击左侧角色定位。勾选同一地块的成员可共同移动。点击相邻地块预览方向和精力，再点一次确认。要移动到相邻队友所在的地块，先点当前小队所在格，再按相同方式预览并确认。采集、交谈和休整等操作通过左侧“行动”打开，物品和装备通过“背包”管理。远征队标题旁可收起或展开面板。
- 按住地图上的鼠标左键拖动，可向任意方向平移。也可用 WASD 平移。用滚轮朝鼠标指向的位置放大看细节，或拉远查看岛屿全貌。单击地块可选中。邻格揭雾后可看到地貌，亲自到访后才发现地点、人物和物资。物资可在地块详情查看和采集。
- 湖面需要绕行，沿岸陆地按所在的地形计费。拉近镜头时，挡住当前小队成员的树冠或高物件会在人物周围淡出。
- 普通移动 1 精力，山地、沼泽 2 精力；洛恩走山地为 1 精力。精力不足时可选择其他角色或结束一天。
- “结束一天”统一推进日期，每人的精力回到个人上限，可行动者恢复部分 HP/MP。生命为 0 的重伤者需要同地队友用药或治疗，不能等次日自行站起。
- 每人拥有独立背包，不限容量，同地免费交接。消耗品旁标有持有者，选中卡片可查看用途。地图上可直接从背包使用疗伤药或澄露，目标须同地，使用不耗精力。武器、防具、饰品各一个槽位，背包面板也列出属性、技能和专长。
- 踏入陌生 NPC 所在格会自动开始相遇剧情，之后可通过“行动”再次交谈。点剧情画面推进相遇、对白和尾声。到了抉择节点，右下角才显示当前可选的分支。交谈、同行与交付任务免费，可以暂缓或拒绝同行。

## 战斗

- 同地最多四人同时出战，首次上场每人支付 2 精力；候补上场也付一次，同场返回不重复扣。首次遭遇敌人时，精力不足也可应战，费用最多扣至 0。
- 连续速度条决定行动先后和频率。点战场上的敌人或右侧卡片可选中目标，金环和箭头会标记所选敌人。普攻和单体攻击技能使用该目标，辅助单体技能会要求选择队友。
- 鼠标悬停在战斗指令或终结技上可查看说明。普通技能消耗 MP。战斗攻击、辅助与防守为本人充能，地图采集不充能。
- 左侧满能量按钮可以申请终结技，当前原子动作结束后额外释放，清空能量但保留正常行动。终结技包括伤害、治疗和护盾。
- 只有本人正常行动时能用其背包的恢复道具，可用多件，用后仍可攻击或施法。
- 换人占一次正常行动，只能换同地合格候补。战场右上角可切换「自动战斗」和打开「道具」，自动战斗开启时按钮高亮。手动和自动释放带点燃效果的技能或终结技时，都能引燃当前干燥森林。
- 撤退不退还精力或已使用的道具，已出战者承受 10% 最大生命损伤。前置移动者退回来源格。

进入敌人所在格后才会发现遭遇。森林和沼泽里的伏击敌人会抢先行动。敌人强度固定。胜利后本战倒下的友方恢复至 1 HP。结算画面列出战利品与参战队员状态，点击“继续远征”后离开。主角参与且候补也无法继续时才判失败。主角不在的败队留原地待援，全队失能也会失败。

## 环境与故事

火焰可能点燃当前森林，水术可灭火并留下潮湿。战斗只处理当前战场；森林燃料和六邻蔓延在日结算处理。雨天先灭火。地图、战场和后续剧情保留实际后果。

六名伙伴每局都在合法地形中出现，位置随种子改变。顶部显示远征目标和全队共享的探索度。“旅途手记”记录已接触人物、原件持有人以及已发现归航站的位置。

文书需要由实际持有人到场交付，共享地图不会传送物品或代替 NPC 授权。故事存在拒绝、隐私、分歧和证据不足的结果；调查和首领战都不是撤离前置条件。你到站后可以继续行动，最终确认前会列出到站者和异地成员。结算会按实际伤势、位置及个人故事给出尾声，异地未撤离不等于自动死亡。

## 遗器

遗器全队共享，本局每种可取得一次。战斗胜利后，符合条件的遭遇有机会掉落遗器。到访后，可从“行动”调查少数地块的旧物。伊芙的送药回执和澄汐的水位标尺也有固定谢礼。

获得遗器会进入剧情，点击画面查看来历和效果。“背包”的“遗器”页可查阅持续生效和已触发的效果。中途退出时，“继续上次远征”会回到已存下的遗器剧情页。

## 存档与退出

移动、换日、物品变更、剧情抉择和战斗结算会自动保存。关窗后从菜单“继续上次远征”恢复。战斗中保留战前检查点，继续时重进同一遭遇，不保存半个动画或重复发奖励。

存档位于 `%APPDATA%/Godot/app_userdata/归灯之野 · 白栎远征/expedition.json`，前一次文件保留为 `.bak`。设置音效音量也会记住。此版为单槽局内存档，没有跨局永久成长。

## 版本范围

包含半径 8、217 格地图，三种职业、六名伙伴、八类普通敌人、两类精英、一个可选首领、完整首章分支，以及共用 3D 骨骼小人偶、近战接近/接触/归位、弓箭/火/水/治疗/护盾效果及七类终结技演出。美术和演出属于 MVP 规格，尚无配音、复杂动作、联机或商业版内容量。岛外蓝色海格为不可通行的景观，不改变 217 格陆地与迷雾规则。
