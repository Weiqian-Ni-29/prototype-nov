# 地块上的行动选项

日期：2026-11-03。状态：汇总现有草案供讨论，未实现；具体费用与部分交互细则未定，不新增已确认的玩法承诺。

## 1. 行动由什么决定

可执行行动由当前所选角色的位置、地形、地块状态、主要遭遇、在场角色的技能、当日行动点与持有资源共同决定，不是每格展示一套相同按钮。

进入地块后自动更新角色所在格及相邻一圈视野，不再额外收费执行一次“探索”来揭开迷雾。查看信息与真正改变状态的调查、采集需要区分。

AP 属于实际执行角色；未定费用仍标为草案，交谈/同行/交付免费与逐人首次参战收费已确认。

## 2. 选项表

| 选项 | 何时可用 | 效果与范围 | 当前费用状态 |
| --- | --- | --- | --- |
| 查看地块 | 地块处于可见或已探索状态 | 查看地形、已观察内容与可用行动；不可见处只显示最后记录 | 免费 |
| 移动 | 有相邻可达格且行动条件满足 | 所选角色或同行成员移动，刷新一圈视野 | 草案普通格每人 1 AP、山地 2 AP，专长减费另算 |
| 采集或领取物资 | 有未耗尽、可获取的资源 | 物资进入执行者个人背包，部分可恢复 | 暂定 1 AP，产量/再生待定；不增加终结技充能 |
| 调查或执行事件 | 有遗迹、路标或事件 | 阅读和剧情选择免费；实际物理行为按对应规则处理 | 不收点击选项费，实际行动费用另行预览 |
| 与 NPC 交谈 | 同格有可交互 NPC | 对话有选项，可改变后续、支线和结局 | 不耗 AP，物品代价明示 |
| 邀请/拒绝同行、交付任务 | 满足对应剧情与物品条件 | 可直接、任务后或战后结识，不强制入队，无收费招募动作 | 不耗 AP，交付与同步领奖不重复收费 |
| 使用恢复物资或救援 | 个人持物且合法目标同地 | 恢复或扶起重伤，消耗对应物品；技能救援按技能费用 | 地图用物资不耗 AP；战斗仅自己正常行动期间不限件数用物资、不占正常行动 |
| 休整 | 地点安全且满足休整条件 | 当前参与休整的同地角色恢复，不治疗异地成员 | 原 2 AP、1 补给和恢复比例均待重新确认；与每日自然恢复分开 |
| 点燃 | 在场角色有对应技能，当前格无未清除敌人且森林可被点燃 | 改变当前格环境，预览火场和林地损失 | 草案 1 AP，MP 与冷却规则待定；雨天或潮湿阻止点燃 |
| 灭火或浸湿 | 在场角色有对应技能，当前格存在有效变化 | 灭火或改变当前格湿润状态，不自动治疗或产补给 | 草案 1 AP，MP 与冷却规则待定，无有效变化不扣费 |
| 交战 | 敌人格或事件有战斗入口 | 同时最多四人在场，可用同地候补替换；敌人强度固定且入场前提示危险 | 每角色每场首次上场付个人 AP，暂以 2 为讨论值，同场重返不重复付 |
| 确认撤离或继续等待 | 主角已到站 | 到站不自动结束，可等同伴或继续探索；确认时到站者撤离，异地成员有对应剧情 | 0 AP，无期限/必做主线，确认前可取消 |

并非所有格子都有主要遭遇，且目前一格最多一个主要遭遇对象；地点设施与状态不自动变成额外可重复领奖事件。

## 3. 敌人格是特殊情况

现有草案不是“先进入敌人格，再随意采集、休整，最后决定是否交战”。主动进入敌人格前先预览风险、合法阵容与预算，确认后移动和开战连续执行；不满足完整入场条件就不先扣移动费。

敌人固定驻守，已知敌人格按预览与预算主动进入；森林/沼泽可隐藏伏击，已探索地形不自动暴露敌人。真正未知伏击 AP 不够也开战、参战费扣至 0 不欠费，敌人首次行动提前后恢复连续速度条。战斗期间能否并发其他地图行动仍待定，不因界面切换跳过敌人行动。

终结技充能只在战斗中获得，攻击和辅助技能给使用者充能；地图采集、拾取和对话不充能。终结技可伤害/恢复/辅助，满后行动间隙插队额外释放，用后清空、战后保留。普通技能不统一 CD，耗 MP 并占正常行动。

## 4. 与地块无关的操作

查看面板和切换选中角色免费。个人携带恢复与任务物品，同格才能交接，背包不限容量、不计负重；交接 AP 与换装时机待定。武器、防具、饰品各一槽。

“结束一天”为全局操作，玩家统一推进全队日期，提前结束提示剩余 AP；不扣每日口粮，HP/MP 按规则部分恢复、AP 回个人上限，重伤不自动站起，不是单个角色独立睡到下一天。

## 5. 展示建议

建议地块面板优先显示当前有意义的选项；缺少行动点、技能或物资时明确说明原因。先显示预期费用、恢复或环境后果，再由玩家确认，不因查看信息提前扣费。

有药草资源的普通森林格可以提供查看、采集和移动，满足条件时也可使用恢复物品、休整或点燃。招募、交战和地图技能需要相应的 NPC、敌人或施法者实际在场。
