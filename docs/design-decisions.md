# 已确认设计与待定事项

日期：2026-11-03。状态：当前讨论基线；仅设计文档，尚未开发。

本文件汇总本次讨论中确认的方向。详细规则见对应文档；建议数值与候选功能不能自动视为已经确认。

## 已确认或先行采用

| 项目 | 当前决策 |
| --- | --- |
| 当前阶段 | 先聊清楚设计，只更新文档，不创建工程、编写游戏代码或批量制作美术 |
| 远征队 | 可以招募多名成员，不采用原先五人的总上限；可以分头行动 |
| 伙伴投放 | MVP 每局放入全部六名可招募伙伴，各自出现一次；位置按地形和剧情约束随机安排，不要求玩家找到或招募全部 |
| 相遇规则 | 人物身份、初遇场景和地形应合理对应；精灵医者一般在森林相遇，其他角色的具体偏好表仍为建议 |
| 角色行动点 | 按角色独立计算，各自设定上限；没有统一点数基准，也没有全队或分队共享额度 |
| 角色差异 | 可以有战斗力强但机动力弱、攻击较弱但机动力强的角色；具体数值待定 |
| 主角 | 主角本人同样是角色，具有对应属性并遵循同一套资源规则，参战占一个位置 |
| 角色基础系统 | 生命、魔力、探索行动力、技能和装备栏；其他战斗数值仍需细化 |
| 每日恢复 | 生命与魔力每天恢复一部分，不默认直接回满；行动点每天恢复到各角色自己的上限 |
| 地块物资与恢复 | 地块可提供物资，其中部分可消耗用于恢复；具体物品、获取条件、恢复效果与使用费用待细化 |
| 参战资格 | 只有同一地块的角色能参加当地战斗，单场最多四人，允许少于四人；异地不能直接支援 |
| 战斗体验 | 借鉴《崩坏：星穹铁道》的角色回合制体验方向，支持手动与自动；具体系统不是整套默认采用 |
| 战斗行动顺序 | 按速度逐人行动，敌我使用同一排序依据；固定轮内排序还是连续行动条、同速处理仍待细化 |
| 终结技与能量 | 需要终结技；每个角色独立积累能量，出击与收集可蓄能，能量满后可释放自己的终结技，不使用全队共享能量池 |
| 弱点条 | 不设独立弱点条或韧性条；不因此删除既有元素克制与环境修正 |
| 环境时间 | 战斗只推进当前战场环境，不因战斗快进异地分队或火场 |
| 地图 | 地块与地图外轮廓均为六边形，地图中心向外 8 圈（不含中心格），共 217 格；采用六邻接 |
| 初始视野与探索 | 每个角色只看到所在格及相邻一圈六格，地图边缘裁剪；其余区域在迷雾中，移动探索后逐步发现，已探索但不可见的区域不提供实时信息 |
| 撤离 | 没有撤离天数限制；开局给大致方向，找到撤离点后可离开，不新增必做剧情解锁条件 |
| 撤离生成 | 算法保证撤离点离出生点足够远，同时验证实际路径与可达性；具体距离门槛待定 |
| 地图美术 | 手绘桌游风 |
| 肖像与剧情美术 | 日系二次元方向，参考《崩坏：星穹铁道》的审美，以原创生成素材建立角色一致性 |
| 探索与战斗角色 | 小人偶表现，简化动作制作；具体技术形式待定 |
| 世界观 | 先采用暂名《归灯之野》的奇幻边境：旧灯路衰落，旅途温暖与历史隐情并存 |
| 首章与伙伴 | 先采用《地图上没有的驿站》与岑枝、洛恩、伊芙、砾牙、弥烬、澄汐的人物方向；名称、台词及细节可修订 |

## 仍待讨论，不自动定案

1. 每日生命与魔力部分恢复、行动点回到各自上限，以及地块恢复物资已确认；仍需确定恢复量、每日口粮是否消耗、物资是否再生及是否实际携带和交接。
2. 各角色的行动点上限、战斗属性、技能与数值；新招募角色当日点数，以及战斗入场如何逐人收费。
3. 每日恢复之外的魔力来源、道具使用时机与费用、技能冷却；速度排序细则、出击与收集的具体蓄能触发、终结技释放时机和能量消耗/保留规则。终结技、个人能量与不设弱点条均已确认，不重新列为候选。
4. 装备槽位、转交和换装时机；背包、负重、外观变化是否需要。
5. 远征队人数是否有软上限；同地超过四人的候补、换人和战败处理。
6. 重伤移动与救援、主角死亡规则是否调整、异地角色如何完成撤离。
7. 六边形朝向、移动快捷键、分散角色的共享信息细节、撤离距离与路线成本参数；地图尺寸、外轮廓和基础一圈视野已确认。
8. 日结算全图环境的具体推进方式；局部环境轮、燃料、传播与潮湿期限。当前仅战场局部推进已确认，细则仍属建议。
9. 营地恢复、补给与魔力收益、库存功能及相应费用。
10. 主角自定义范围、正式游戏名、详细对白分支和跨局叙事结构。
11. 六名伙伴的具体地形偏好、备选初遇场景、分布距离与关联任务路程；每局全部六人的投放方式已确认。

## 已废止的旧约束

- 远征队最多三人或五人、伙伴必须始终共同移动。
- 全队每日共享固定行动点，或所有角色统一以某个固定点数为基准。
- 方格四方向移动、八邻格视野与四邻格火势传播。
- 原先暂定的 16×16、256 格地图方案，现改用半径 8 圈、217 格的六边形地图。
- 固定十二天内撤离及超时失败。
- 每个战斗轮推进全地图环境。
- 每轮只能指定一名角色用主动技能，其余固定自动普攻的旧战斗形式。
