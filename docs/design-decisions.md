# 已确认设计与待定事项

更新日期：2026-11-04。状态：当前讨论基线；仅设计文档，尚未开发。

本文件汇总本次讨论中确认的方向。详细规则见对应文档；建议数值与候选功能不能自动视为已经确认。

## 已确认或先行采用

| 项目 | 当前决策 |
| --- | --- |
| 当前阶段 | 先聊清楚设计，只更新文档，不创建工程、编写游戏代码或批量制作美术 |
| 远征队 | 可以招募多名成员，不采用原先五人的总上限；可以分头行动 |
| 伙伴投放 | MVP 每局放入全部六名可招募伙伴，各自出现一次；位置按地形和剧情约束随机安排，不要求玩家找到或招募全部 |
| 相遇规则 | 人物身份、初遇场景和地形应合理对应；精灵医者一般在森林相遇，其他角色的具体偏好表仍为建议 |
| 同行与对话 | 交谈、剧情对话选项、邀请同行与交付任务不耗 AP；无单独收费的招募动作。可直接同行、任务后同行或战后结识，玩家可以拒绝 |
| 分支故事 | 多支线、多选择、多结局属于核心要求；因果合理、前后连贯，覆盖已设计分支的后续与终点 |
| 角色行动点 | 按角色独立计算，各自设定上限；没有统一点数基准，也没有全队或分队共享额度 |
| 角色差异 | 可以有战斗力强但机动力弱、攻击较弱但机动力强的角色；具体数值待定 |
| 主角 | 主角本人同样是角色，具有对应属性并遵循同一套资源规则，参战占一个位置 |
| 主角开局 | 可从几种职业模板选择，具体职业、技能与数值后续集中设计 |
| 新伙伴 AP | 首次加入当天获得个人上限 AP，同一角色当日只初始化一次；不自动恢复 HP/MP 或解除已有重伤 |
| 角色基础系统 | 生命、魔力、探索行动力、技能和装备栏；其他战斗数值仍需细化 |
| 每日恢复 | 生命与魔力每天恢复一部分，不默认直接回满；行动点每天恢复到各角色自己的上限 |
| 日期推进 | 全队共用日期，由玩家统一结束一天，提前结束提示各角色剩余 AP |
| 物资与口粮 | 不设每日强制口粮；物资主要用于恢复和任务，由个人携带，同格才能交接，不共享异地背包 |
| 背包与装备 | 背包不限容量、不计负重，同格交接免费；武器、防具、饰品各一槽 |
| 战斗用物资 | 只在我方角色自己的正常行动时使用，不占正常行动，之后仍可攻击/施法；不限件数，只消耗个人持有物品 |
| 地图用物资 | 不耗探索 AP，只消耗持有物品；救援仍需同地可行动队友实际执行 |
| 地块物资与恢复 | 地块可提供物资，其中部分可消耗用于恢复；具体物品、获取条件、恢复效果与使用费用待细化 |
| 参战资格 | 只有同一地块的角色能参加当地战斗，同时在场最多四人，允许少于四人；异地不能直接支援 |
| 候补与换人 | 可以用同地候补替换，替换占一次正常行动；场上全倒时仍可由符合参战条件的健康候补继续战斗 |
| 参战行动费 | 每名实际出战者本场首次上场支付个人探索 AP，候补首次上场同样支付；同场换下再换回不重复收费，具体点数待定 |
| 战斗体验 | 借鉴《崩坏：星穹铁道》的角色回合制体验方向，支持手动与自动；具体系统不是整套默认采用 |
| 战斗行动顺序 | 连续速度行动条，敌我按速度逐人行动，快角色同样战斗时间行动更多次；同速与换人进度细则待定 |
| 普通主动技能 | 消耗 MP 并占正常行动，不统一设置冷却；后续正常行动可在 MP 足够时继续选择同技能 |
| 敌人强度与驻守 | 强度固定不按人数缩放，固定驻守不跨格巡逻/追击；可见遭遇提前提示，隐藏伏击不泄露精确阵容 |
| 地形遮挡与伏击 | 平原等开阔地形部分敌人可提前看见，森林/沼泽可隐藏伏击；永久点亮地形不代表自动暴露隐藏敌人 |
| 伏击危险迹象 | 每次伏击前提供可察觉迹象，例如脚印、蛛丝或气泡；只提示风险，不直接揭露敌人阵容 |
| 伏击入场 AP | 预算不足仍开战，首次参战费用最多扣到 0、不欠费，不因刚移动完而卡死；普通已知遭遇保持预算检查 |
| 终结技充能 | 每人独立，只在战斗中获得；攻击与治疗/保护等辅助技能给使用者充能，辅助增长量可较少；进入遭遇、地图采集、拾取和对话不充能 |
| 终结技类型 | 可为伤害、恢复或辅助效果，不要求所有角色的大招都是伤害 |
| 终结技插队与消耗 | 可在其他角色行动间隙插队；是额外行动，不占用下一次正常行动；释放后个人能量清空，重新积攒 |
| 充能保留 | 战后未使用的个人终结技充能保留到下一场；不在地图中通过收集、交谈或交接充能 |
| 主角与战斗胜败 | 主角 HP 归零但队友仍可继续；胜利后本战倒下的友方恢复至 1 HP。主角参与的战斗中，场上全倒且无符合条件的健康同地候补可继续时，本局失败 |
| 重伤与救援 | 非主角队伍战败者留在遭遇地点，等其他角色同地用恢复物资或治疗技能救援；次日自然恢复不能自动扶起，全远征队无人能行动或救援时本局失败 |
| 弱点条 | 不设独立弱点条或韧性条；不因此删除既有元素克制与环境修正 |
| 环境时间 | 战斗只处理当前格火伤、点燃/灭火等状态；森林燃料按天消耗，跨格传播日结算发生，不因战斗快进异地火场 |
| 地图 | 地块与地图外轮廓均为六边形，地图中心向外 8 圈（不含中心格），共 217 格；采用六邻接 |
| 基础地形 | 平原、森林、山地、遗迹、沙漠、沼泽六类；沼泽移动与环境效果待定 |
| 探索与观测 | 角色用所在格及一圈揭雾，所有己方记录共享；已探索格永久点亮可实时观测，仅未探索区遮雾，不再离开后暗化或只显示最后记录 |
| 撤离 | 没有撤离天数限制；开局给大致方向，找到撤离点后可离开，不新增必做剧情解锁条件 |
| 撤离确认与等待 | 到站只解锁主动确认，不自动结束；可等待同伴并继续管理或探索。确认结束时到站者撤离，异地已加入角色有对应未撤离剧情，不自动死亡 |
| 撤离生成 | 算法保证撤离点离出生点足够远，同时验证实际路径与可达性；具体距离门槛待定 |
| 地图美术 | 2.5D 手绘桌游六边形立体沙盘，不是纯平面棋盘 |
| 肖像与剧情美术 | 日系二次元方向，参考《崩坏：星穹铁道》的审美，以原创生成素材建立角色一致性 |
| 探索与战斗角色 | 复用同一套立体 3D 小人偶及骨骼，简单动画是首版要求；探索和战斗都为 2.5D，战斗固定斜视镜头 |
| 战斗背景 | 对应实际交战地块的地貌、环境和天气，技能改变当前格后同步表现，不能用无关通用背景 |
| 世界观 | 先采用暂名《归灯之野》的奇幻边境：旧灯路衰落，旅途温暖与历史隐情并存 |
| 首章与伙伴 | 先采用《地图上没有的驿站》与岑枝、洛恩、伊芙、砾牙、弥烬、澄汐的人物方向；名称、台词及细节可修订 |

## 仍待讨论，不自动定案

1. 每日恢复额度、物品内容和资源再生；个人背包不限容量、不计负重、同格免费交接、无每日口粮、地图用物资免费已确定。
2. 各职业和伙伴 AP/战斗属性/技能数值、首次参战费具体点数；新伙伴首次加入当天获个人上限 AP 已确定。
3. 同速/换人进度、攻击/辅助充能量、多段计数与隔日充能；普通技能不统一 CD、辅助技能可充能、终结技可恢复/辅助均已确定。
4. 三类装备效果、角色限制、换装时机与费用、外观变化；三个槽位和同格免费交接已确定。
5. 远征队人数是否有软上限；候补受伤、换人后的行动条与全倒补位细节。同地换人与首次上场收费已确定。
6. 重伤搬运、救援费用、主角战斗外归零的操作细则与双方同时全倒的判定。非主角战败留原地、同地救援、全队失能失败及主动撤离/等待/异地结局已确认。
7. 六边形朝向、移动快捷键、撤离距离与路线成本；地图大小、基础一圈揭雾、共享探索和永久点亮实时观测已确认。
8. 战斗火伤结算间隔、燃烧持续天数、潮湿期限等数值；燃料按天消耗、传播在日结算已确定。
9. 营地恢复、补给与魔力收益、库存功能及相应费用。
10. 主角职业模板的具体内容与外观自定义、正式游戏名、详细对白分支和跨局结构；开局选职业模板已确定。
11. 六名伙伴的具体地形偏好、备选初遇场景、分布距离与关联任务路程；每局全部六人的投放方式已确认。
12. 敌人候选名单/数量与技能、伏击首次提前幅度和主动侦察；必有可察觉迹象、先手提前及沼泽加入已确认，沼泽通行与环境待定。
13. 3D 人偶头身比/模型规格、具体骨架动作、镜头角度与地块资产；2.5D 探索/战斗、共用 3D 人偶、简单骨骼动画和地貌匹配背景已确定。

## 已废止的旧约束

- 远征队最多三人或五人、伙伴必须始终共同移动。
- 全队每日共享固定行动点，或所有角色统一以某个固定点数为基准。
- 方格四方向移动、八邻格视野与四邻格火势传播。
- 原先暂定的 16×16、256 格地图方案，现改用半径 8 圈、217 格的六边形地图。
- 固定十二天内撤离及超时失败。
- 每个战斗轮推进全地图环境。
- 每轮只能指定一名角色用主动技能，其余固定自动普攻的旧战斗形式。
- 主角生命一归零就立即结束远征、交谈或邀请同行要额外支付行动点，以及用短任务与十二个模板限制全部故事分支的旧约束。

本文不是开发启动指令。后续继续讨论时，应同步更新对应详细文档和本记录，避免重新引入已废止约束。
