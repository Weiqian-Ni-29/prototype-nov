# 维洛丹 · Veylodan

一款以种子生成地图的单人奇幻远征游戏。旅人在陌生的村庄醒来，随后带着村民给的补给出发，寻找结束诸神战争的办法。

- 地图有 217 格。种子决定出生地貌、村庄、角色位置和各地故事。可以自由折返。
- 25 名伙伴各有种族、性格、经历、技能和终结技。角色在交易、歇脚、亡灵、寻宝、普通和精英战斗等节点中出现。
- 探索度达到 20%、40%、60%、80% 时推进主线，随后可在地图上找到战神卡德兰。
- 旅人使用独立于六种元素的重力魔法。火与水造成的燃烧、潮湿等场地效果在本场战斗内结算。

运行游戏请用 Godot 4.7.2 打开 `game/project.godot`，或执行 `godot_console --path game`。运行完整回归用 `python tools/run_checks.py --visual`。
