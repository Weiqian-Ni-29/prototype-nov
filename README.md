# 鲸肚里的酒馆

酒馆被鲸吞了。带上牌去找出口，账可以出去再结。

- 每趟旅途有六段途中遭遇和一场终点决战。选定动作后才揭晓遭遇，结算后继续前进。
- 低、中、高赌注决定可能遭遇的范围和得失量级。途中可能遇到战斗、商店、宝箱、休整或事件。
- 途中可遇见伙伴，也可以花灯铢招募。入队后可在角色界面突破，提升伙伴棋子的能力。
- 战斗胜利发放战利品。打断卡在鲸嘴边的捕鲸机绞盘，就能回到海面。
- 对战使用 3×4 棋盘。玩家卡组至少 3 张，总张数无上限。每回合全队可以移动或普攻一次，法力足够时可以连续出牌，点击「结束回合」交给敌方。近战普攻会受到反伤，远程普攻免反伤。击倒对方主战者获胜。

运行游戏请用 Godot 4.7.2 打开 `game/project.godot`，或执行 `godot_console --path game`。运行完整回归用 `python tools/run_checks.py --visual`。
